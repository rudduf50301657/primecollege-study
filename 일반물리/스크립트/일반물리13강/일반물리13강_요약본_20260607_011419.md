# 일반물리13강 요약본
- **일시**: 2026-06-07
- **주제**: 전자기 유도 — 패러데이 법칙, 발전기, 변압기, 인덕턴스

---

## 배경

전기 현상과 자기 현상은 서로 영향을 주고받는 불가분의 관계이다. 라디오파(전자기파)가 그 대표적 산물이다. 이번 강의(13강)는 전기와 자기가 어떻게 얽혀 있는지를 일반물리 수준에서 다룬다.

---

## 주요 내용

### 1. 복습 — 전자기 기초

| 법칙/개념 | 내용 |
|---|---|
| 오른손 법칙 | 전류 방향 → 자기장 방향 결정 |
| 비오-사바르 법칙 | 전류(원인)로부터 자기장(결과) 크기 계산 |
| 전기 선속(가우스 법칙) | 닫힌 면을 통과하는 전기력선의 양 → 내부 전하량에 비례 |
| 자기 선속 | 단면을 통과하는 자기장선의 양 (Φ = B·A·cosθ) |

### 2. 전자기 유도 (패러데이의 법칙)

- **원인**: 자기장의 변화 (자석의 움직임, 코일의 움직임)
- **결과**: 도선에 전류(기전력) 유도
- **렌츠의 법칙**: 유도 전류는 자기 선속 변화를 **방해하는** 방향으로 발생
  - 자석이 가까워질 때 → 자기 선속 증가 → 반대 방향 자기장 생성
  - 자석이 멀어질 때 → 자기 선속 감소 → 같은 방향 자기장 생성
- **자기장 변화가 없으면** 전류 발생 없음

#### 솔레노이드(1차·2차 코일)에서의 전자기 유도
- 1차 코일에 **일정 전류** 통전 중: 자기장 변화 없으므로 2차 코일에 전류 없음
- 스위치를 **닫는 순간**: 자기장이 0→증가 → 2차 코일에 유도 전류 발생 (변화에 반하는 방향)
- 스위치를 **여는 순간**: 자기장이 감소 → 2차 코일에 반대 방향 유도 전류 발생

### 3. 패러데이 법칙 (수식)

유도 기전력(EMF):

$$\varepsilon = -N\frac{\Delta\Phi}{\Delta t}$$

- N: 코일 감은 수
- ΔΦ: 자기 선속 변화량 (Φ = B·A·cosθ)
- 음의 부호: 렌츠의 법칙 반영 (변화에 반하는 방향)

자기 선속 변화의 세 가지 원인:
1. **자기장(B) 변화**
2. **단면적(A) 변화**
3. **각도(θ) 변화** → 발전기의 원리

#### 예제 풀이
- 10cm×20cm 직사각형 코일, 균일한 자기장, 코일 평면이 자기장과 이루는 각도가 30°→45°로 변할 때 자기 선속 변화 계산
  - 주의: B와 면의 수직 벡터(법선벡터) 사이 각도를 써야 함 → 평면이 30°기울면 법선은 60°
- 유도 기전력 = −ΔΦ/Δt 적용하여 볼트 단위로 계산

### 4. 운동 기전력 (Motional EMF)

- ㄷ자형 도체 레일 위에 도체 막대를 속도 v로 이동 시키면 면적 증가 → 자기 선속 증가 → 기전력 발생
- 공식: **ε = BLv**
  - B: 자기장, L: 막대 길이, v: 막대 속도

#### 예제
- B = 0.6 T, L = 0.3 m, 원하는 기전력 1.5 V → 필요 속도 = 약 8.3 m/s

### 5. 발전기 (Generator)

- 균일한 자기장 안에서 코일을 각속도 ω로 회전
- 자기 선속: Φ = BA·cos(ωt)
- 유도 기전력: **ε = NBAω·sin(ωt)** (최대값 ε₀ = NBAω)
- 발전기는 **교류(AC)**를 생성
  - 발전소 → 가정까지는 교류로 전송
  - 노트북 충전기·USB 등 = 교류→직류(DC) 변환기

#### 예제
- 1m² 코일, 50회 감음, 자기장 B, 100 rpm → ω = 10π rad/s → ε₀ ≈ 47.1 V

### 6. 변압기 (Transformer)

- 1차 코일에 교류 인가 → 자기 선속 변화 → 2차 코일에 기전력 유도
- **권수비 법칙**: V₁/V₂ = N₁/N₂
  - 예: 1차 100회(220V) → 2차 50회 → 출력 110V
- 전력(P = VI)은 이상적으로 보존 (전압↑ → 전류↓)
- 송전 시 고전압 사용 이유: 전력 손실 ∝ I² (전류를 낮춰 손실 최소화)
  - 발전소 → 가정까지 수만 V로 송전 후 단계적으로 220V까지 강압

### 7. 인덕턴스 (Inductance)

#### 자체 인덕턴스 (Self-Inductance)
- 코일에 전류가 변하면 자기장 변화 → 그 변화를 방해하는 유도 기전력이 자기 자신에게 발생 (셀프 인덕턴스)
- 결과: 스위치를 닫아도 전류가 즉시 최대값에 도달하지 못하고 **시간 지연** 발생

- 정의: NΦ = LI (L = 인덕턴스)
- 유도 기전력: **ε = −L·(dI/dt)**
- 인덕터에 걸리는 전압은 전류의 **시간 변화율**에 비례

#### 단위
- 인덕턴스 단위: **헨리(H)**
- 1H = 1V·s/A

#### 솔레노이드 인덕턴스
$$L = \mu_0 \frac{N^2 A}{\ell}$$
(N: 감은 수, A: 단면적, ℓ: 길이)

- 자성체 심을 넣으면 자기 투자율 증가 → 인덕턴스 증가
- 비자성체 심: 인덕턴스 작음

## 핵심 공식/개념

| 공식 | 의미 |
|---|---|
| Φ = B·A·cosθ | 자기 선속 |
| ε = −N·ΔΦ/Δt | 패러데이 법칙 (유도 기전력) |
| ε = BLv | 운동 기전력 |
| ε₀ = NBAω | 발전기 최대 기전력 |
| V₁/V₂ = N₁/N₂ | 변압기 권수비 |
| P_손실 ∝ I² | 송전 전력 손실 |
| ε = −L·dI/dt | 인덕터 전압 |
| L = μ₀N²A/ℓ | 솔레노이드 인덕턴스 |

**렌츠의 법칙**: 유도 전류는 항상 자기 선속 변화를 방해하는 방향으로 흐른다.

## 과제/시험 관련

- 자기 선속 계산 시 **B와 법선벡터 사이 각도(θ)** 주의 — 코일 평면과 B 사이 각도와 혼동 금지
- 패러데이 법칙 적용 절차: ΔΦ 계산 → ΔΦ/Δt → 부호(렌츠) 판단
- 운동 기전력: ε = BLv, 세 변수 중 두 개 알면 나머지 계산
- 발전기 문제: rpm → rad/s 변환 필수 (×2π/60)
- 인덕턴스 단위 헨리(H) 및 유도 기전력 ε = −L·dI/dt 암기
- 전기 회로의 세 소자: **저항(R), 캐패시터(C), 인덕터(L)** — RLC 회로는 이후 강의에서 심화

# 일반물리14강 요약본
- **일시**: 2026-06-07
- **주제**: 전자회로 기초 - 축전기(캐패시터), 전류/전압/저항, 키르히호프 법칙

---

## 배경
- 일반물리 14강은 이론 강의의 마지막 강 (15강은 예제 풀이)
- 전자회로를 구성하는 3가지 기본 소자(저항, 인덕터, 캐패시터)를 중심으로 기초 회로 이론 소개
- 담당: 첨단부품부 박성색 교수

---

## 주요 내용

### 1. 축전기(캐패시터, Capacitor)
- **개념**: 전하를 저장하는 소자. 양전하판과 음전하판 사이에 전기장이 형성되어 전하를 축적
- **전기용량(캐패시턴스, C)**: 단위 전압당 저장 가능한 전하량의 능력치
  - 단위: 패럿(F) = 쿨롱/볼트. 실생활 소자는 마이크로패럿(μF) 수준으로 매우 작음
- **평행판 축전기**: C = ε₀·A/d (단면적에 비례, 판 간격에 반비례)
- **유전체**: 두 판 사이에 유전체(비유전율 κ)를 삽입하면 정전용량이 κ배 증가 (C_d = κC)
- **저장 에너지**: W = Q²/(2C) = (1/2)CV²

### 2. 전류(Current)
- 전하의 연속적인 흐름. 양전하가 흐르는 방향으로 정의
- I = ΔQ/Δt (단위: 암페어, A = 쿨롱/초)
- 전위차(전압)가 존재하면 높은 전위 → 낮은 전위 방향으로 전류 흐름

### 3. 저항(Resistance)
- 전하 흐름을 방해하는 척도. 단위: 옴(Ω)
- **비저항(ρ)**: 물질 고유 특성. R = ρL/A (길이에 비례, 단면적에 반비례)
  - 도체(구리 등): 비저항 매우 작음 / 부도체(유리 등): 비저항 매우 큼
- **가변저항**: 볼륨 조절 등에 활용
- **전력 소비**: 저항에서 전기 에너지가 열로 소비됨

### 4. 옴의 법칙
- V = IR (전압 = 전류 × 저항)
- 전력: P = IV = I²R = V²/R

### 5. 키르히호프 법칙(Kirchhoff's Laws)
- **KVL (전압 법칙)**: 닫힌 회로 한 바퀴의 전위차 합 = 0
  - 전원에서 올라간 전압만큼 저항들에서 떨어져야 함
- **KCL (전류 법칙)**: 한 접점에서 들어오는 전류의 합 = 나가는 전류의 합

### 6. 저항 연결
- **직렬 연결**: 전류 일정, 합성저항 R_eq = R₁ + R₂ + R₃ + ...
- **병렬 연결**: 전압 일정, 합성저항 1/R_eq = 1/R₁ + 1/R₂ + 1/R₃ + ...

### 7. 축전기 연결
- **병렬 연결**: 전압 일정, 합성 정전용량 C_eq = C₁ + C₂ + C₃ + ... (저항 직렬과 유사)
- **직렬 연결**: 전하량 일정, 합성 정전용량 1/C_eq = 1/C₁ + 1/C₂ + 1/C₃ + ... (저항 병렬과 유사)
- 주의: 저항과 축전기는 직렬/병렬 공식이 서로 반대

## 핵심 공식/개념

| 항목 | 공식 |
|------|------|
| 전하량 | Q = CV |
| 평행판 정전용량 | C = ε₀A/d |
| 유전체 삽입 | C_d = κC |
| 축전기 저장 에너지 | W = Q²/2C = CV²/2 |
| 전류 정의 | I = ΔQ/Δt |
| 옴의 법칙 | V = IR |
| 비저항 | R = ρL/A |
| 전력 | P = IV = I²R = V²/R |
| 저항 직렬 | R_eq = R₁ + R₂ + ... |
| 저항 병렬 | 1/R_eq = 1/R₁ + 1/R₂ + ... |
| 축전기 병렬 | C_eq = C₁ + C₂ + ... |
| 축전기 직렬 | 1/C_eq = 1/C₁ + 1/C₂ + ... |

## 과제/시험 관련
- 15강은 예제 풀이 시간 (이론 강의 종료)
- 직렬/병렬 회로에서 등가저항·등가정전용량 계산 연습 필요
- 복합 회로(직렬+병렬 혼합) 풀이 순서: 병렬 먼저 단순화 → 직렬 계산
- 헤어드라이어 예제: 220V, 1000W → 전류 약 4.5A, 저항 약 49Ω (실생활 연계)
- 사진 플래시 예제: 300V, 120μF → 저장 에너지 5.4J (축전기 에너지 활용 사례)

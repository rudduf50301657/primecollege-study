# 일반물리15강 요약본

- **일시**: 2026-06-07
- **주제**: 전기장·자기장·전자기유도·기초 전자회로 예제 풀이 (하반기 마지막 강의)

---

## 배경

일반물리 하반기 마지막 강의(15강)로, 이전 8강처럼 예제 풀이 위주로 진행되었다. 하반기 강의에서 파동 파트보다 전기장·자기장 파트 예제가 많아, 해당 내용들을 모아서 복습하는 시간을 가졌다.

---

## 주요 내용

### 1. 전기장 (Electric Field)

| 소주제 | 핵심 내용 |
|--------|----------|
| 쿨롱의 법칙과 전기장 | 전하 사이에 작용하는 쿨롱 힘을 장(field)으로 표현. 전기장 E = F/q (단위 전하당 힘) |
| 정전기력 vs 중력 | 수소 원자에서 정전기력 >> 중력. 원자 세계에서는 중력 무시 가능 |
| 전기력의 벡터 합산 | 여러 전하에 의한 힘은 벡터 합산. 같은 방향이면 단순 합산, 각도 있으면 sin/cos 분해 |
| 전기장 계산 예제 | 점전하 Q에서 특정 거리의 전기장 세기 계산. 단위: N/C (뉴턴/쿨롱) |
| 등가속 운동 | 균일한 전기장 속 양성자의 가속 운동 → 등가속도 공식 v² = v₀² + 2aS 적용 |
| 가우스 법칙 | 폐곡면을 통과하는 전기선속 = 내부 전하량/ε₀. 점전하 구면에서 쿨롱 법칙과 동일한 결과 도출 |

### 2. 자기장 (Magnetic Field)

| 소주제 | 핵심 내용 |
|--------|----------|
| 도선에 작용하는 자기력 | F = IL × B (전류, 길이, 자기장의 외적). 각도 90°일 때 sin=1 → 최대 힘 |
| 예제 | 25만A 전류, 2.0T 자기장, 10cm 도선 → 5N 힘 |
| 자기장 속 하전입자 운동 | 자기력이 속도에 항상 수직 → 등속 원운동. 반지름 r = mv/(qB) |
| 질량 분석기 응용 | 입자를 자기장에 입사시켜 원의 반지름으로 질량 역산 가능 |
| 비오-사바르 법칙 | 전류 도선 주변에 오른손 법칙으로 자기장 형성. 자기장 크기 계산 공식 |
| 평행 도선 사이의 힘 | 같은 방향 전류 → 인력, 반대 방향 전류 → 척력 |
| 솔레노이드 | 앙페르 법칙으로 내부 자기장 유도. B = μ₀nI (n: 단위길이당 감은 횟수) |

### 3. 전자기유도 (Electromagnetic Induction)

| 소주제 | 핵심 내용 |
|--------|----------|
| 자기선속 변화 | 면적과 자기장의 각도 변화로 자기선속 변화량 계산. 각도 주의: 면의 법선벡터 기준 |
| 패러데이 법칙 | 유도 기전력 = -ΔΦ/Δt. 자기선속 변화에 반대 방향으로 전압 유도 |
| 운동 기전력 | 도체 막대를 자기장 속에서 이동 시 EMF = BLv. 막대 이동으로 회로 면적 증가 → 자기선속 변화 |
| 발전기 원리 | 자기장 속에서 코일을 회전 → 자기선속이 주기적으로 변화 → 교류 기전력 발생 |
| 발전기 예제 | 코일 면적 1.5m², 50회 감기, 1450 rpm, 기전력 최대값 47.1V |
| 인덕터(자기 인덕턴스) | 자기선속 ∝ 전류인 소자. 솔레노이드 자체 인덕턴스 L = μ₀N²A/l |
| 인덕턴스 예제 계산 | L = 6.3 × 10⁻⁶ H |

### 4. 기초 전자회로

| 소주제 | 핵심 내용 |
|--------|----------|
| 축전기(커패시터) | Q = CV. 저장 에너지 U = Q²/2C = CV²/2. 예제: 충전량, 에너지, 전하 개수 계산 |
| 평행판 축전기 전기용량 | C = ε₀A/d (면적에 비례, 간격에 반비례) |
| 저항과 비저항 | R = ρL/A. 길이 2배 → 저항 2배, 단면적 2배 → 저항 절반 |
| 전력 소모 | P = IV = I²R = V²/R |
| 키르히호프 법칙 | 전압 법칙(KVL): 폐회로 전압합 = 0 / 전류 법칙(KCL): 한 점 전류의 합 = 0 |
| 저항 직렬연결 | R_total = R₁ + R₂ + ... (예: 2Ω + 3Ω + 5Ω = 10Ω) |
| 저항 병렬연결 | 1/R_total = 1/R₁ + 1/R₂ + ... 각 저항에 걸리는 전압 동일 |
| 축전기 직·병렬 연결 | 저항과 반대: 병렬 C_total = C₁+C₂+..., 직렬 1/C_total = 1/C₁+1/C₂+... |
| 혼합 회로 축전기 예제 | C23(병렬) → 직렬 결합 → 전체 정기용량 계산, 전하량 Q = 48μC |

## 핵심 공식/개념

| 공식 | 내용 |
|------|------|
| F = kq₁q₂/r² | 쿨롱의 법칙 |
| E = kQ/r² | 점전하의 전기장 |
| Φ = EA·cosθ, Φ = Q/ε₀ | 가우스 법칙 |
| F = qvB·sinθ, F = ILB·sinθ | 자기력 |
| r = mv/(qB) | 자기장 속 하전입자 원운동 반지름 |
| B = μ₀I/(2πr) | 비오-사바르: 직선 도선 자기장 |
| B = μ₀nI | 솔레노이드 내부 자기장 |
| EMF = -ΔΦ/Δt | 패러데이 전자기유도 법칙 |
| EMF = BLv | 운동 기전력 |
| L = μ₀N²A/l | 솔레노이드 자기 인덕턴스 |
| Q = CV, U = CV²/2 | 축전기 전하량 및 에너지 |
| R = ρL/A | 비저항과 저항 관계 |

## 수업 마무리 언급 사항

- **상반기**: 역학(물체 운동) 위주
- **하반기**: 전기·자기 현상 위주
- 앞으로 전공 심화 학습 시 일반물리·미적분이 밑거름이 됨
- 전자회로를 제대로 공부하려면 인덕터·커패시터 + 미분방정식까지 필요
- 강사 격려 멘트로 강의 마무리

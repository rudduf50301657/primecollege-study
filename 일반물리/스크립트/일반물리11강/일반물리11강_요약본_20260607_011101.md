## 주요 내용

### 1. 전하와 쿨롱의 법칙

- **전하(charge)**: 양전하(+)와 음전하(-) 두 종류가 존재
  - 같은 부호 → 척력(밀어냄)
  - 다른 부호 → 인력(당김)
- **금속 내 전하 이동**: 고체에서는 음전하(전자)만 이동하며, 양전하(원자핵)는 이동하지 않음
- **전하량 보존 법칙**: 우주 전체의 양전하와 음전하의 수는 항상 동일 (쌍으로 존재)
- **대전 상태**: 양전하와 음전하의 수가 불균형한 상태
  - 음으로 대전 = 전자가 들어온 상태
  - 양으로 대전 = 전자가 빠져나간 상태
- **쿨롱의 법칙**: 두 전하 사이의 정전기력
  - F = kQ₁Q₂ / r²
  - 전하량에 비례, 거리의 제곱에 반비례
  - 쿨롱 상수 k = 1/(4πε₀) ≈ 9×10⁹ N·m²/C²
- **기본 전하량**: 전자 1개의 전하량 e ≈ 1.6×10⁻¹⁹ C (전하량의 최소 단위)
  - 1쿨롱 = 전자 약 6.24×10¹⁸개

### 2. 수소 원자 예시 (정전기력 vs 중력 비교)

- 수소 원자 내 양성자–전자 사이의 정전기력이 중력보다 약 10³⁹배 크다
- 원자 수준에서 중력은 무시 가능, 정전기력이 지배적

### 3. 전기장(Electric Field)

- **장(Field)**: 공간 각 위치에 벡터가 정의된 것. 어떤 위치에 물체를 놓았을 때 받을 단위량당 힘을 표현
- **전기장 E의 정의**: E = F / q₀ (단위 전하당 받는 힘)
  - 양전하가 있으면 방사형으로 바깥을 향하는 전기장 형성
  - 음전하가 있으면 방사형으로 안을 향하는 전기장 형성
  - 공식: E = kQ / r²
- **전기장의 벡터 표현**: E = kQ/r² × r̂ (단위벡터 방향)
- **중첩 원리 적용**: 한 지점의 전기장 = 모든 전하가 만드는 전기장의 벡터합
- **균일한 전기장**: 무한히 넓은 대전판 두 장(양극·음극)을 마주 보게 배치하면 판 사이에 균일한 전기장 형성
- **양성자가 균일한 전기장 내 운동**: F = qE = ma → 등가속 운동

### 4. 가우스 법칙

- **전기 선속(Electric Flux)**: 어떤 표면을 관통하는 전기장의 양
  - Φ = EA cosθ (전기장과 면의 법선 방향 사이 각도 θ)
- **가우스 법칙**: 폐곡면을 통과하는 전체 전기 선속은 내부 전하량에 비례
  - ΦE = Q내부 / ε₀
  - 선속이 바깥을 향하면 내부에 양전하, 안을 향하면 음전하, 0이면 내부 전하 균형
- **적용 예시**: 점전하를 둘러싼 반경 r인 구면에 대해 가우스 법칙 적용 → 쿨롱의 법칙과 동일한 결과 도출

### 5. 전위(Electric Potential)와 전압

- **전기적 위치 에너지(포텐셜 에너지)**: 전하를 전기장 안에서 이동시킬 때 필요한 일
  - U = kQq / r
- **전위(V)**: 단위 전하당 위치 에너지
  - V = U / q = kQ / r
  - 단위: 볼트(V) = J/C (줄 퍼 쿨롱)
- **일상 예시**: 배터리·콘센트의 "몇 볼트"가 이 전위(전압)를 의미
- **전위차**: 두 지점 사이의 전위 차이 (ΔV = -Ed, 균일한 전기장에서)
  - 양전하는 높은 전위에서 낮은 전위로 이동하며 위치 에너지 감소

## 과제/시험 관련

- 쿨롱의 법칙 계산 (전하량·거리 주어지면 힘 계산)
- 여러 전하가 있을 때 중첩 원리로 합력 계산
- 전기장 크기·방향 구하기 (점전하, 균일한 전기장)
- 균일한 전기장에서 하전 입자의 등가속 운동 문제 (v² = v₀² + 2ad 형태 활용)
- 가우스 법칙 개념 이해 (폐곡면 내부 전하와 선속의 관계)
- 전위·전위차 개념 이해 및 계산 (전압 = 볼트, 나중에 전기 회로에서 핵심)

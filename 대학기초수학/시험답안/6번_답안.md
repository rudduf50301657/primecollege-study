# 대학기초수학 시험 6번 답안

## 문제 (배점 5점)

다음 중 방정식 2sin(x) + 1 = 0 의 해가 아닌 것은?

① -1/6 π  ② -17/6 π  ③ 23/6 π  ④ 5/6 π

## 답: ④ 5/6 π

> **오답 주의:** ① -π/6을 해가 아닌 것으로 착각하기 쉬우나, sin(-π/6) = -1/2 이므로 정상적인 해이다. 5π/6은 sin 값이 +1/2 이므로 해가 아님.

## 풀이

### 근거 강의: 11~12강 「삼각함수 (1)(2)」 — 삼각방정식

2sin(x) + 1 = 0 → sin(x) = -1/2

sin(x) = -1/2 의 일반해: x = 7π/6 + 2nπ 또는 x = 11π/6 + 2nπ (= -π/6 + 2nπ)

| 선지 | 계산 | sin 값 | 해 여부 |
|------|------|--------|--------|
| ① -π/6 | sin(-π/6) = -1/2 | ✓ | 해임 |
| ② -17π/6 | = -17π/6 + 2π = -5π/6, sin(-5π/6) = -1/2 | ✓ | 해임 |
| ③ 23π/6 | = 23π/6 - 2π·1 = 11π/6, sin(11π/6) = -1/2 | ✓ | 해임 |
| ④ 5π/6 | sin(5π/6) = sin(π-π/6) = 1/2 ≠ -1/2 | ✗ | **해 아님** |

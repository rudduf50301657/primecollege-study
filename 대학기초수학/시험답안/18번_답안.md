# 대학기초수학 시험 18번 답안

## 문제 (배점 5점)

∠C = 90° 인 직각삼각형 ABC에 대하여, 삼각형 ABC의 넓이가 16일 때, AB²의 최솟값은?

## 답: ② 64

> **오답 주의:** ① 100은 a,b를 특정 값으로 잘못 설정한 경우. ③ 49는 산술-기하 평균 부등식을 잘못 적용한 경우. a²+b² ≥ 2ab 임에 주의.

## 풀이

### 근거 강의: 9강 「일차함수와 이차함수」 / 11강 「삼각함수」 — 산술-기하 평균 부등식

AC = a, BC = b로 놓으면:

**넓이 조건:**
(1/2)ab = 16 → ab = 32

**피타고라스:**
AB² = a² + b²

**산술-기하 평균 부등식 (AM-GM):**

a² + b² ≥ 2ab = 2 × 32 = 64

등호 조건: a = b (이등변 직각삼각형)

∴ **AB²의 최솟값 = 64**

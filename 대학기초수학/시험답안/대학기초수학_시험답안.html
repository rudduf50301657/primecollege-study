좌표공간의 두 점 \(A(-1,1,-2)\), \(B(2,4,1)\)에 대하여 선분 \(\overline{AB}\)가 \(xy\)평면과 만나는 점을 \(P\)라 할 때, 선분 \(\overline{BP}\)의 길이는?
답: ③ \(\sqrt{3}\)
⚠️ 오답 주의: \(2\sqrt{3}\)은 \(BP\)가 아닌 \(AP\)를 구하거나 내분비를 반대로 적용한 경우.
STEP 1. 선분 AB를 매개변수로 표현
점 A에서 점 B로 향하는 직선 위의 점을 매개변수 \(t\)로 나타낸다.
\[P = A + t(B - A) = (-1+3t,\; 1+3t,\; -2+3t)\]
STEP 2. xy평면과 만나는 조건 (z = 0)
\(xy\)평면은 \(z = 0\)인 평면이므로, \(z\)좌표를 0으로 놓고 \(t\)를 구한다.
\[-2 + 3t = 0 \implies t = \frac{2}{3}\]
즉, 점 \(P\)는 선분 \(AB\)를 \(A\)에서 \(B\) 방향으로 \(2:1\)로 내분하는 점이다.
STEP 3. P의 좌표 계산
\[x = -1 + 3 \cdot \tfrac{2}{3} = 1,\quad y = 1 + 3 \cdot \tfrac{2}{3} = 3,\quad z = 0\]
\[\therefore P(1, 3, 0)\]
STEP 4. BP의 길이
두 점 사이의 거리 공식 \(d = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}\)을 적용한다.
\[\overline{BP} = \sqrt{(2-1)^2 + (4-3)^2 + (1-0)^2} = \sqrt{1+1+1} = \boxed{\sqrt{3}}\]

\(\dfrac{3}{4}\pi < \theta < \pi\) 인 \(\theta\)에 대하여 \(\sin\theta\cos\theta = -\dfrac{12}{25}\) 일 때, \(\sin\theta + \cos\theta\)의 값은?
답: ④ \(-\dfrac{1}{5}\)
⚠️ 오답 주의: \(\frac{1}{5}\)는 부호 결정에서 \(\theta\)의 범위를 무시한 경우. \(\frac{3}{4}\pi < \theta < \pi\)에서 \(\sin\theta+\cos\theta < 0\).
STEP 1. \(s = \sin\theta + \cos\theta\)로 치환
양변을 제곱하면 \(\sin\theta\cos\theta\)와의 관계가 나온다.
\[s^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta\]
\(\sin^2\theta + \cos^2\theta = 1\) (항등식)이므로:
\[s^2 = 1 + 2\sin\theta\cos\theta\]
STEP 2. 조건 대입
\[s^2 = 1 + 2\left(-\frac{12}{25}\right) = 1 - \frac{24}{25} = \frac{1}{25}\]
\[\therefore s = \pm\frac{1}{5}\]
STEP 3. 부호 결정
\(\theta\)의 범위에서 \(\sin\theta + \cos\theta\)의 부호를 판단한다.
\[\theta = \tfrac{3}{4}\pi \;\Rightarrow\; \sin\theta + \cos\theta = \tfrac{\sqrt{2}}{2} - \tfrac{\sqrt{2}}{2} = 0\]
\[\theta = \pi \;\Rightarrow\; \sin\theta + \cos\theta = 0 + (-1) = -1\]
따라서 \(\frac{3}{4}\pi < \theta < \pi\) 구간에서 \(\sin\theta + \cos\theta < 0\)
\[\therefore \sin\theta + \cos\theta = \boxed{-\frac{1}{5}}\]

답: ② 11
⚠️ 오답 주의: 9는 정사영 축소 비율 \(|\cos\alpha|\)를 빠뜨린 경우.
STEP 1. AC 거리
\[AC = \sqrt{(\sqrt{2})^2 + 5^2 + 3^2} = \sqrt{2+25+9} = \sqrt{36} = 6\]
STEP 2. 접선 조건에서 ∠APC = 90°
직선이 구와 한 점 \(P\)에서 접하므로 \(CP \perp AP\). 따라서 \(\angle APC = 90°\)이고, \(AC\)가 원의 지름이 된다.
\[\text{원의 반지름} = \frac{AC}{2} = 3,\quad \text{원의 넓이} = 9\pi\]
STEP 3. 정사영 넓이 최댓값
정사영 넓이 = 원래 넓이 × \(|\cos\alpha|\). 최댓값을 위해 \(|\cos\alpha|\)의 최댓값을 구한다.
\[\vec{d} = \overrightarrow{AC} = (\sqrt{2},\,5,\,3),\quad |\vec{d}| = 6\]
\(\hat{z} = (0,0,1)\)의 \(\vec{d}\) 방향 성분을 빼면 \(\vec{d}\)에 수직인 성분이 남는다.
\[\hat{z} \cdot \hat{d} = \frac{3}{6} = \frac{1}{2}\]
\[|\cos\alpha|_{\max} = \sqrt{1 - \left(\frac{1}{2}\right)^2} = \sqrt{\frac{3}{4}} = \frac{\sqrt{3}}{2}\]
\[\text{최대 정사영 넓이} = 9\pi \times \frac{\sqrt{3}}{2} = \frac{9\sqrt{3}}{2}\pi\]
STEP 4. a+b 구하기
\[\frac{b\sqrt{3}}{a}\pi = \frac{9\sqrt{3}}{2}\pi \implies b = 9,\; a = 2 \quad\text{(서로소)}\]
\[\therefore a + b = \boxed{11}\]

두 직선 \(3x+2y-5=0\), \(3x+y-1=0\)의 교점을 지나고 \(2x-y-4=0\)에 평행한 직선의 \(y\)절편은?
답: ① 6
⚠️ 오답 주의: 2는 기울기를 \(-2\)로 잘못 구한 경우. \(2x-y-4=0 \Rightarrow y=2x-4\)이므로 기울기는 \(2\).
STEP 1. 교점 구하기
두 직선을 연립하여 교점 좌표를 구한다.
\[3x + 2y = 5 \;\cdots (1)\]
\[3x + y = 1 \;\cdots (2)\]
\[(1)-(2):\; y = 4\]
\[(2)에 대입:\; 3x + 4 = 1 \implies x = -1\]
\[\text{교점} = (-1,\, 4)\]
STEP 2. 평행 직선의 방정식
\(2x - y - 4 = 0\)의 기울기는 2. 점 \((-1, 4)\)를 지나고 기울기 2인 직선:
\[y - 4 = 2(x + 1) \implies y = 2x + 6\]
\[\therefore y\text{절편} = \boxed{6}\]

답: ④ \(\dfrac{5}{6}\pi\)
⚠️ 오답 주의: \(-\frac{1}{6}\pi\)를 해가 아닌 것으로 착각하기 쉬우나, \(\sin(-\frac{\pi}{6}) = -\frac{1}{2}\)이므로 정상적인 해.
STEP 1. 방정식 정리
\[2\sin x + 1 = 0 \implies \sin x = -\frac{1}{2}\]
STEP 2. 각 선지 확인
각 값의 \(\sin\) 값이 \(-\frac{1}{2}\)인지 확인한다.
\[\sin\!\left(-\frac{\pi}{6}\right) = -\frac{1}{2} \;\checkmark\]
\[\sin\!\left(-\frac{17\pi}{6}\right) = \sin\!\left(-\frac{17\pi}{6} + 2\pi\right) = \sin\!\left(-\frac{5\pi}{6}\right) = -\frac{1}{2} \;\checkmark\]
\[\sin\!\left(\frac{23\pi}{6}\right) = \sin\!\left(\frac{23\pi}{6} - 2\pi\right) = \sin\!\left(\frac{11\pi}{6}\right) = -\frac{1}{2} \;\checkmark\]
\[\sin\!\left(\frac{5\pi}{6}\right) = \sin\!\left(\pi - \frac{\pi}{6}\right) = +\frac{1}{2} \neq -\frac{1}{2} \;\;\boldsymbol{\times}\]
\[\therefore \boxed{\frac{5}{6}\pi}\text{ 는 해가 아니다}\]

⚠️ 오답 주의: \(\frac{2}{3}\)는 원의 중심을 원점으로 잘못 설정한 경우.
STEP 1. 원의 중심과 반지름
\[\text{중심} = \left(\frac{-3+1}{2},\, 0\right) = (-1,\, 0),\quad r = \frac{|-3-1|}{2} \div 1 = 2\]
STEP 2. 접선 조건: 점과 직선 사이 거리 = 반지름
원과 직선이 한 점에서 만나려면 중심에서 직선까지의 거리가 반지름과 같아야 한다.
\[\frac{|k(-1) + 0 - 2|}{\sqrt{k^2 + 1}} = 2\]
\[\frac{|k+2|}{\sqrt{k^2+1}} = 2\]

\[(k+2)^2 = 4(k^2+1)\]
\[k^2 + 4k + 4 = 4k^2 + 4\]
\[3k^2 - 4k = 0 \implies k(3k-4) = 0\]
\[k = 0 \;\text{또는}\; k = \frac{4}{3}\]
양수 \(k\)이므로:
\[\therefore \boxed{k = \frac{4}{3}}\]

⚠️ 오답 주의: 13은 인수분해를 잘못한 경우. \((2x+1)\)이 \(2x^2+ax+b\)의 인수여야 연속 구간 해가 된다.
STEP 1. 해의 구조 분석
해가 \(x \le 3\) (음의 무한대부터 3까지의 연속 구간)이 되려면, \(f(x) = (2x+1)(2x^2+ax+b)\)에서 \(x=3\)이 경계이고 \(x=-\frac{1}{2}\)도 해에 포함되어야 한다.

STEP 2. 인수분해
\[2x^2 + ax + b = (2x+1)(x-3) = 2x^2 - 5x - 3\]
비교하면 \(a = -5\), \(b = -3\).
STEP 3. 검증
\[f(x) = (2x+1)^2(x-3)\]
\((2x+1)^2 \ge 0\)이므로 \(f(x) \le 0 \iff x - 3 \le 0 \iff x \le 3\) ✓
\[\therefore a^2 + b^2 = 25 + 9 = \boxed{34}\]

\[(3,3),\; (3,4),\; (4,3),\; (4,4)\]

\[(3,3):\; \text{치역} = \{3\} \to f(3) \ne 3,\, f(4) \ne 3,\, f(3) \ne f(4) \Rightarrow 3\times 2 = 6\]
\[(3,4):\; \text{치역} = \{3,4\} \to \text{정확히 1개 새 원소 필요} \Rightarrow 10\]
\[(4,3):\; \text{대칭} \Rightarrow 10\]
\[(4,4):\; \text{치역} = \{4\} \to f(3) \ne 4,\, f(4) \ne 4,\, f(3) \ne f(4) \Rightarrow 3\times 2 = 6\]
\[\therefore 6 + 10 + 10 + 6 = \boxed{32}\]

\(\{|x|\le 2,\;|y|\le 2\}\)의 모든 점 \((a,b)\)에 대해 \((x-a)^2+(y-b)^2 \le 1\)을 만족하는 영역은?
답: ③ (둥근 모서리의 \(-3 \sim 3\) 사각형)
⚠️ 오답 주의: ①은 직각 모서리. 원의 합집합이므로 꼭짓점은 반드시 둥글다.
STEP 1. 영역 해석
정사각형 \([-2,2] \times [-2,2]\)의 모든 점을 중심으로 반지름 1인 원을 그린 합집합이다.
이는 정사각형을 모든 방향으로 1만큼 확장한 민코프스키 합에 해당한다.
STEP 2. 결과 형태
변 부분은 직선으로 1만큼 바깥으로 (\(-3 \sim 3\)), 꼭짓점 \((\pm 2, \pm 2)\) 부근은 반지름 1인 사분원으로 둥글게 처리된다.
\[\text{→ 둥근 모서리의 } [-3,3]\times[-3,3] \text{ 형태}\]

삼차방정식 \(x^3 + x - 2 = 0\)의 두 허근 \(\alpha, \beta\)에 대해 \(\dfrac{\beta}{\alpha} + \dfrac{\alpha}{\beta}\)는?
답: ② \(-\dfrac{3}{2}\)
⚠️ 오답 주의: \(\frac{1}{2}\)는 분모 \(\alpha\beta = 2\)에 대입할 때 부호 실수.
STEP 1. 인수분해
\[x^3 + x - 2 = (x - 1)(x^2 + x + 2) = 0\]
실근 \(x = 1\), 허근 \(\alpha, \beta\)는 \(x^2 + x + 2 = 0\)의 근.
STEP 2. 근과 계수의 관계
\[\alpha + \beta = -1,\quad \alpha\beta = 2\]
STEP 3. 식 변환
\(\frac{\beta}{\alpha} + \frac{\alpha}{\beta}\)를 통분하면 \(\frac{\alpha^2 + \beta^2}{\alpha\beta}\)이다.
\[\frac{\alpha^2+\beta^2}{\alpha\beta} = \frac{(\alpha+\beta)^2 - 2\alpha\beta}{\alpha\beta} = \frac{(-1)^2 - 2(2)}{2} = \frac{1-4}{2} = \boxed{-\frac{3}{2}}\]
📖 근거: 9강 「일차함수와 이차함수」 — 근과 계수의 관계
18
\(\angle C = 90°\)인 직각삼각형 \(ABC\)의 넓이가 16일 때, \(\overline{AB}^2\)의 최솟값은?
답: ② 64
⚠️ 오답 주의: 100은 \(a, b\)를 특정 값(6, 8 등)으로 대입한 경우. AM-GM 부등식으로 최솟값을 구해야 한다.
STEP 1. 조건 설정
\(AC = a\), \(BC = b\)로 놓으면:
\[\text{넓이} = \frac{1}{2}ab = 16 \implies ab = 32\]
\[\overline{AB}^2 = a^2 + b^2 \quad\text{(피타고라스 정리)}\]
STEP 2. 산술-기하 평균 부등식 (AM-GM)
\(a^2 + b^2 \ge 2ab\) (등호: \(a = b\))
\[a^2 + b^2 \ge 2 \times 32 = 64\]
\[\therefore \overline{AB}^2_{\min} = \boxed{64}\]
등호 조건: \(a = b\), 즉 이등변 직각삼각형일 때.
📖 근거: 9강 — 부등식, 산술-기하 평균 부등식
19
이차방정식 \(x^2 + 2x + k = 0\)의 두 근 \(\alpha, \beta\)에 대해 \(\alpha^2 + \beta^2 = 8\)일 때, \(k\)는?
답: ② -2
⚠️ 오답 주의: -1은 \(\alpha^2+\beta^2 = (\alpha+\beta)^2 - 2\alpha\beta\) 에서 2\(\alpha\beta\)가 아닌 \(\alpha\beta\)를 뺀 경우.
STEP 1. 근과 계수의 관계
\[\alpha + \beta = -2,\quad \alpha\beta = k\]
STEP 2. \(\alpha^2 + \beta^2\)를 근과 계수로 표현
\(\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta\) 항등식을 이용한다.
\[\alpha^2+\beta^2 = (-2)^2 - 2k = 4 - 2k = 8\]
\[-2k = 4 \implies \boxed{k = -2}\]
검증
판별식 \(D = 4 - 4(-2) = 12 > 0\) → 서로 다른 두 실근 ✓
📖 근거: 9강 「일차함수와 이차함수」 — 근과 계수의 관계
20
두 벡터 \(\vec{a} = (m-2, 3)\), \(\vec{b} = (2m+1, 9)\)가 평행할 때, \(m\)은?
답: ① 7
⚠️ 오답 주의: 5는 전개 시 \(-6m - 3\)의 부호를 잘못 처리한 경우.
평행 조건: 외적 = 0
두 벡터 \((a_1, a_2)\), \((b_1, b_2)\)가 평행이면 \(a_1 b_2 - a_2 b_1 = 0\)
\[(m-2)(9) - (3)(2m+1) = 0\]
\[9m - 18 - 6m - 3 = 0\]
\[3m - 21 = 0 \implies \boxed{m = 7}\]
검증
\(\vec{a} = (5, 3)\), \(\vec{b} = (15, 9) = 3 \cdot (5, 3) = 3\vec{a}\) → 평행 ✓

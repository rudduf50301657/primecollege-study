# 대학기초수학 시험 13번 답안

## 문제 (배점 5점)

상수 a > 0 에 대하여 구간 0 ≤ x ≤ 2 에서 정의된 이차함수 f(x) = x² - 2ax + 2a² 의 최솟값이 10일 때, 함수 f(x)의 최댓값으로 가장 적절한 것은?

## 답: ③ 18

> **오답 주의:** ① 20은 최댓값을 f(2)로 잘못 계산한 경우. ② 24는 a 값을 잘못 구한 경우. 꼭짓점이 구간 밖(a>2)에 있으므로 최솟값은 f(2)에서 발생함에 주의.

## 풀이

### 근거 강의: 9강 「일차함수와 이차함수」 — 이차함수의 최대·최소

**f(x) = x² - 2ax + 2a² = (x - a)² + a²**

꼭짓점: x = a, 최솟값 = a²

**a의 범위에 따른 경우 분류:**

a > 0이고 최솟값 = 10.

- 0 ≤ a ≤ 2 이면: 최솟값 = a² = 10 → a = √10 ≈ 3.16 > 2. 모순. ✗
- a > 2 이면: 구간 [0,2]에서 f는 감소. 최솟값은 x = 2에서 발생.

**a > 2인 경우:**

f(2) = 4 - 4a + 2a² = 10
2a² - 4a - 6 = 0
a² - 2a - 3 = 0
(a - 3)(a + 1) = 0
a = 3 (a > 0이므로)

**최댓값 (x = 0에서):**

f(0) = 2a² = 2 × 9 = **18**

### 관련 보충자료

9강 보충자료(연습문제)에 제한된 구간에서 이차함수의 최대·최소 문제가 수록되어 있다.

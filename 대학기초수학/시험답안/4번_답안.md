# 대학기초수학 시험 4번 답안

## 문제 (배점 5점)

좌표평면의 두 벡터 a⃗ = (x+1, 2), b⃗ = (1, -x) 가 서로 수직일 때, x의 값은?

## 답: ① 1

> **오답 주의:** ③ 2는 내적을 (x+1)·(-x) + 2·1 = 0 으로 잘못 계산한 경우(성분 순서 혼동). 반드시 같은 위치의 성분끼리 곱해야 한다.

## 풀이

### 근거 강의: 14강 「벡터」 — 벡터의 내적과 수직 조건

두 벡터가 수직이면 내적이 0이다.

a⃗ · b⃗ = (x+1)(1) + (2)(-x) = 0

x + 1 - 2x = 0

1 - x = 0

**x = 1**

### 관련 보충자료

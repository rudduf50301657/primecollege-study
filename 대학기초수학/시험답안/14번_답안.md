# 대학기초수학 시험 14번 답안

## 문제 (배점 5점)

연립방정식 { x - y + 1 = 0, x² - 2y² - 2 = 0 } 의 해를 x = α, y = β 라고 할때, α + β 의 값은?

## 답: ④ -3

> **오답 주의:** ① -2는 α만 답한 경우. ② -5는 부호 실수. x = y-1 대입 후 정리할 때 부호에 주의.

## 풀이

### 근거 강의: 9강 「일차함수와 이차함수」 — 연립방정식

**1차 식에서 x를 y로 표현:**

x - y + 1 = 0 → x = y - 1

**2차 식에 대입:**

(y - 1)² - 2y² - 2 = 0
y² - 2y + 1 - 2y² - 2 = 0
-y² - 2y - 1 = 0
y² + 2y + 1 = 0
(y + 1)² = 0
**y = -1** (β = -1)

**x 구하기:**

x = y - 1 = -1 - 1 = **-2** (α = -2)

**α + β = -2 + (-1) = -3**

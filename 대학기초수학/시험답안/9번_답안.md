# 대학기초수학 시험 9번 답안

## 문제 (배점 5점)

두 상수 a, b에 대하여 부등식 (2x+1)(2x²+ax+b) ≤ 0 의 해가 x ≤ 3 일때, a²+b²의 값은?

## 답: ① 34

> **오답 주의:** ② 13은 a=-2, b=-3 등으로 잘못 인수분해한 경우. 핵심은 (2x+1)이 2x²+ax+b의 인수여야 해가 x≤3 (연속 구간)이 되며, (2x+1)²(x-3) 형태가 되어야 한다는 점.

## 풀이

### 근거 강의: 10강 「부등식의 영역」 / 9강 「일차함수와 이차함수」 — 이차부등식

**해가 x ≤ 3 이 되려면:**

f(x) = (2x+1)(2x²+ax+b) 에서 x = 3이 경계, x > 3에서 f(x) > 0

2x²+ax+b 가 (2x+1)을 인수로 가져야 한다 (x = -1/2도 해에 포함되므로).

2x²+ax+b = (2x+1)(x-3) = 2x²-5x-3 으로 인수분해되면:

f(x) = (2x+1)(2x+1)(x-3) = **(2x+1)²(x-3)**

- (2x+1)² ≥ 0 (항상 0 이상)
- x-3 ≤ 0 일 때 f(x) ≤ 0 → **x ≤ 3** ✓

따라서 a = -5, b = -3

**a² + b² = 25 + 9 = 34**

### 관련 보충자료

# 대학기초수학 시험 17번 답안

## 문제 (배점 5점)

삼차방정식 x³ + x - 2 = 0 의 서로 다른 두 허근을 각각 α, β 라고 하자. 이때 β/α + α/β 의 값은?

## 답: ② -3/2

> **오답 주의:** ① 1/2는 αβ=2를 분모에 넣을 때 부호 실수. ③ -1/2는 (α+β)²=1만 사용하고 -2αβ를 빠뜨린 경우.

## 풀이

### 근거 강의: 9강 「일차함수와 이차함수」 — 근과 계수의 관계

**인수분해:**

x³ + x - 2 = (x-1)(x²+x+2) = 0

실근 x = 1, 허근 α, β는 x²+x+2 = 0 의 근.

**근과 계수의 관계:**
- α + β = -1
- αβ = 2

**β/α + α/β 계산:**

β/α + α/β = (α² + β²) / (αβ) = ((α+β)² - 2αβ) / αβ

= ((-1)² - 2·2) / 2 = (1 - 4) / 2 = **-3/2**

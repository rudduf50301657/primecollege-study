# 대학기초수학 시험 19번 답안

## 문제 (배점 5점)

이차방정식 x² + 2x + k = 0 의 서로 다른 두 근을 α, β 라고 할 때, α² + β² = 8 을 성립하게 하는 상수 k의 값은?

## 답: ② -2

> **오답 주의:** ① -1은 α²+β² = (α+β)²-2αβ 공식에서 2αβ 대신 αβ를 뺀 경우. 반드시 **2**αβ를 빼야 한다.

## 풀이

### 근거 강의: 9강 「일차함수와 이차함수」 — 근과 계수의 관계

**근과 계수의 관계:**
- α + β = -2
- αβ = k

**α² + β² 변환:**

α² + β² = (α + β)² - 2αβ = (-2)² - 2k = 4 - 2k

**조건 대입:**

4 - 2k = 8
-2k = 4
**k = -2**

**검증 (서로 다른 두 근):**
D = 4 - 4(-2) = 12 > 0 ✓

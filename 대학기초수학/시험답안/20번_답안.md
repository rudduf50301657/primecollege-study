# 대학기초수학 시험 20번 답안

## 문제 (배점 5점)

좌표평면의 두 벡터 a⃗ = (m-2, 3) 과 b⃗ = (2m+1, 9) 가 서로 평행할 때, 실수 m의 값은?

## 답: ① 7

> **오답 주의:** ④ 5는 전개 시 부호 실수. ③ 3은 9m-18=0으로 뒷항(-6m-3)을 빠뜨린 경우.

## 풀이

### 근거 강의: 14강 「벡터」 — 벡터의 평행 조건

두 벡터가 평행하면 외적이 0 (ad - bc = 0):

(m-2)(9) - (3)(2m+1) = 0

9m - 18 - 6m - 3 = 0

3m - 21 = 0

**m = 7**

**검증:** a⃗ = (5, 3), b⃗ = (15, 9) = 3(5, 3) = 3a⃗ ✓ (평행)

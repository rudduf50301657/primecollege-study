# 대학기초수학 시험 2번 답안

## 문제 (배점 5점)

3/4 π < θ < π 인 θ에 대하여, sinθcosθ = -12/25 를 만족할 때 sinθ + cosθ 의 값으로 옳은 것은?

① 1/5  ② -3/5  ③ 4/5  ④ -1/5

## 답: ④ -1/5

> **오답 주의:** ① 1/5는 s²=1/25까지 맞게 풀었으나 부호 결정에서 θ의 범위를 고려하지 않고 양수를 선택한 경우. 3π/4 < θ < π 에서는 sinθ+cosθ < 0 이므로 반드시 음수.

## 풀이

### 근거 강의: 11강~12강 「삼각함수 (1)(2)」 — 삼각함수의 항등식

sin²θ + cos²θ = 1 항등식과 곱셈 공식을 활용한다.

### 풀이 과정

**s = sinθ + cosθ 로 놓으면:**

s² = sin²θ + 2sinθcosθ + cos²θ = 1 + 2sinθcosθ

sinθcosθ = -12/25 를 대입하면:

s² = 1 + 2 × (-12/25) = 1 - 24/25 = **1/25**

∴ s = ±1/5

**부호 결정 (θ의 범위로 판단):**

3π/4 < θ < π 에서:
- θ = 3π/4 일 때: sinθ + cosθ = √2/2 + (-√2/2) = 0
- θ = π 일 때: sinθ + cosθ = 0 + (-1) = -1

따라서 이 범위에서 sinθ + cosθ < 0

∴ **sinθ + cosθ = -1/5**

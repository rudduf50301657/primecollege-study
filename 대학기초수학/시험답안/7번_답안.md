# 대학기초수학 시험 7번 답안

## 문제 (배점 5점)

좌표평면 위에 길이가 1인 선분 AB 와 점 C 가 있다. AB⃗ · BC⃗ = 0 이고 |AB⃗ + AC⃗| = 4 일때, |BC⃗|의 값은?

## 답: ④ 2√3

> **오답 주의:** ② √10은 |AB⃗+AC⃗|² 전개 시 내적 조건(AB⃗·BC⃗=0)을 적용하지 않고 계산한 경우. ① 3은 |BC⃗|²=12에서 √12=2√3이 아닌 3으로 잘못 계산한 경우.

## 풀이

### 근거 강의: 14강 「벡터」 — 벡터의 내적, 벡터의 크기

**AB⃗ · BC⃗ = 0 → AB⃗ ⊥ BC⃗**

AC⃗ = AB⃗ + BC⃗ 이므로:

|AB⃗ + AC⃗| = |AB⃗ + AB⃗ + BC⃗| = |2AB⃗ + BC⃗| = 4

양변을 제곱하면:

|2AB⃗ + BC⃗|² = 16

= |2AB⃗|² + 2·(2AB⃗)·BC⃗ + |BC⃗|²

= 4|AB⃗|² + 4(AB⃗ · BC⃗) + |BC⃗|²

AB⃗ · BC⃗ = 0, |AB⃗| = 1 이므로:

= 4(1) + 0 + |BC⃗|² = 4 + |BC⃗|²

4 + |BC⃗|² = 16

|BC⃗|² = 12

**|BC⃗| = 2√3**

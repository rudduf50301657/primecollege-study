# 대학기초수학 시험 16번 답안

## 문제 (배점 5점)

좌표평면에서 연립부등식 { |x| ≤ 2, |y| ≤ 2 } 를 만족하는 모든 점 (a, b)에 대하여 부등식 (x-a)² + (y-b)² ≤ 1 을 만족하는 영역을 바르게 나타낸 것은? (단, 경계선은 포함함.)

## 답: ③ (둥근 모서리의 -3~3 사각형)

> **오답 주의:** ① 은 -3~3 정사각형이지만 모서리가 직각. 원의 합집합이므로 꼭짓점 부근은 반드시 둥글게 된다. ② 는 원래 정사각형(-2~2)과 같은 크기로, 반지름 1인 원의 확장을 고려하지 않은 오답.

## 풀이

### 근거 강의: 10강 「부등식의 영역」 — 연립부등식과 영역

**(a, b)의 범위:** |a| ≤ 2, |b| ≤ 2 → 정사각형 [-2, 2] × [-2, 2]

**각 (a,b)에 대해** 반지름 1인 원 (x-a)²+(y-b)² ≤ 1 을 그린다.

**결과 영역 = 정사각형의 모든 점에서 반지름 1인 원의 합집합 (민코프스키 합)**

이는 원래 정사각형을 모든 방향으로 1만큼 확장한 형태:

- 상하좌우 직선 부분: x 범위 -3~3, y 범위 -3~3
- **꼭짓점(±2, ±2) 부근은 반지름 1인 사분원으로 둥글게** 처리

따라서 **-3~3 범위의 둥근 모서리 사각형**인 ③이 정답이다.

| 선지 | 특징 | 판단 |
|------|------|------|
| ① | -3~3 직각 모서리 | ✗ 모서리가 둥글어야 함 |
| ② | -2~2 직각 모서리 | ✗ 크기가 작음 (확장 미반영) |
| ③ | -3~3 둥근 모서리 | ✓ 정답 |
| ④ | -3~3에 내부 사각형 조합 | ✗ 형태 불일치 |

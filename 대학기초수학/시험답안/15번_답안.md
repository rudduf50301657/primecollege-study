# 대학기초수학 시험 15번 답안

## 문제 (배점 5점)

이차함수 y = x² + 4x + a 의 그래프가 x축에 접할 때, 상수 a의 값으로 가장 적절한 것은?

## 답: ② 4

> **오답 주의:** ③ 3은 판별식에서 D = b²-4ac의 계수를 잘못 적용한 경우. x축에 접한다 = 판별식 D = 0.

## 풀이

### 근거 강의: 9강 「일차함수와 이차함수」 — 이차함수와 판별식

x축에 접한다 → 판별식 D = 0 (중근)

y = x² + 4x + a 에서:

D = b² - 4ac = 4² - 4(1)(a) = 16 - 4a = 0

4a = 16

**a = 4**

검증: y = x² + 4x + 4 = (x + 2)² → x = -2 에서 x축에 접함 ✓

### 관련 보충자료

9강 보충자료(연습문제)에 이차함수의 판별식과 x축 접선 조건 관련 유사 문제가 수록되어 있다.

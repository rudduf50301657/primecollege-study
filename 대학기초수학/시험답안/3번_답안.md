# 대학기초수학 시험 3번 답안

## 문제 (배점 5점)

좌표공간에서 점 A(0,0,2)를 지나는 직선이 점 C(√2, 5, 5)를 중심으로 하고 반지름의 길이가 1인 구와 한 점 P에서 만난다. 세 점 A, C, P를 지나는 원을 xy 평면 위로 정사영할 때, 정사영 넓이의 최댓값이 (b√3/a)π 일 때 a+b의 값은? (단, a와 b는 서로소인 자연수)

## 답: ② 11

> **오답 주의:** ① 9는 a=9, b=1로 잘못 설정하거나 정사영 공식에서 cosα 계산을 빠뜨린 경우. ③ 5는 a+b가 아닌 a 또는 b만 답한 경우.

## 풀이

### 근거 강의: 13강 「공간좌표」 — 정사영의 개념, 두 점 사이의 거리

**1. AC 거리 계산:**

AC = √((√2)² + 5² + 3²) = √(2 + 25 + 9) = √36 = 6

**2. AP 길이 (접선 조건: CP ⊥ AP):**

CP = 1 (반지름), AC = 6이므로
AP = √(AC² - CP²) = √(36 - 1) = √35

**3. 원의 반지름:**

∠APC = 90° (접선과 반지름은 수직)이므로 AC가 원의 지름
원의 반지름 = AC/2 = 3, 원의 넓이 = 9π

**4. 정사영 넓이:**

정사영 넓이 = 원의 넓이 × |cosα| (α: 원의 평면과 xy평면이 이루는 각)

원의 평면은 직선 AC를 포함하므로, 평면의 법선벡터는 AC 방향에 수직이다.

AC 방향: d⃗ = (√2, 5, 3), |d⃗| = 6

z축 단위벡터 ẑ = (0,0,1)의 AC에 수직인 성분 크기가 |cosα|의 최댓값:
- ẑ · d̂ = 3/6 = 1/2
- |ẑ_⊥| = √(1 - (1/2)²) = √(3/4) = √3/2

**5. 최대 정사영 넓이:**

9π × √3/2 = (9√3/2)π

따라서 b = 9, a = 2 (서로소)

**a + b = 2 + 9 = 11**

# 대학기초수학 시험 8번 답안

## 문제 (배점 5점)

좌표평면에서 두 점 (-3, 0), (1, 0)을 지름의 양 끝점으로 하는 원과 직선 kx + y - 2 = 0 이 오직 한 점에서 만나도록 하는 양수 k의 값은?

## 답: ① 4/3

> **오답 주의:** ② 2/3은 원의 중심 좌표를 (0,0)으로 잘못 설정한 경우. ④ 1/3은 반지름을 1로 착각한 경우. 지름의 양 끝점이므로 반지름은 거리의 절반인 2.

## 풀이

### 근거 강의: 7강 「평면좌표」 — 원의 방정식, 원과 직선의 위치 관계

**1. 원의 중심과 반지름:**

중심 = ((-3+1)/2, 0) = (-1, 0)
반지름 = |(-1)-(-3)| = 2

**2. 접선 조건 (중심에서 직선까지 거리 = 반지름):**

|k(-1) + 0 - 2| / √(k² + 1) = 2

|-(k + 2)| / √(k² + 1) = 2

(k + 2)² = 4(k² + 1)

k² + 4k + 4 = 4k² + 4

3k² - 4k = 0

k(3k - 4) = 0

k = 0 또는 k = 4/3

양수 k이므로 **k = 4/3**

# 대학기초수학 시험 1번 답안

## 문제 (배점 5점)

좌표공간의 두 점 A(-1, 1, -2), B(2, 4, 1)에 대하여 선분 AB가 xy 평면과 만나는 점을 P라고 할 때, 선분 BP의 길이로 가장 적절한 것은?

## 답: ③ √3

> **오답 주의:** ① 2√3은 AP의 길이가 아닌 BP를 구해야 하는데 착각하여 AB 전체 길이 관련 계산을 할 때 나올 수 있는 오답. ④ √6은 좌표 계산 실수 시 발생.

## 풀이

### 근거 강의: 13강 「공간좌표」 — 2.2 내분점과 외분점

13강에서 배운 공간좌표에서의 내분점 공식을 활용한다.

공간좌표에서 점 A(x₁, y₁, z₁)와 점 B(x₂, y₂, z₂)의 m:n 내분점 P는:

P = ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n), (mz₂+nz₁)/(m+n))

### 풀이 과정

**xy평면과 만나는 점 P 구하기 (z = 0 조건)**

선분 AB를 매개변수로 표현하면:
- P = A + t(B - A) = (-1 + 3t, 1 + 3t, -2 + 3t)

xy평면에서는 z = 0이므로:
- -2 + 3t = 0
- t = 2/3

이는 점 P가 선분 AB를 **A에서 B 방향으로 2:1로 내분**하는 점이라는 의미이다.

**P의 좌표:**
- x = -1 + 3 × (2/3) = -1 + 2 = 1
- y = 1 + 3 × (2/3) = 1 + 2 = 3
- z = 0

∴ P(1, 3, 0)

**BP의 길이 계산 (13강 — 2.1 두 점 사이의 거리):**

BP = √((2-1)² + (4-3)² + (1-0)²)
   = √(1 + 1 + 1)
   = **√3**

# 파이썬 시험 2번 답안

## 문제

다음과 같은 코드가 있을 때 올바른 출력 결과는?

```python
for i in range(1, 4 + 1):
    for j in range(4, 0, -1):
        if j <= i:
            print(j, end = ' ')
        else:
            print(' ', end = ' ')
    print()
```

## 답

출력 결과:

```
      1
    2 1
  3 2 1
4 3 2 1
```

## 풀이

| i | j=4 | j=3 | j=2 | j=1 | 출력 |
|---|-----|-----|-----|-----|------|
| 1 | 공백 | 공백 | 공백 | 1 | `      1` |
| 2 | 공백 | 공백 | 2 | 1 | `    2 1` |
| 3 | 공백 | 3 | 2 | 1 | `  3 2 1` |
| 4 | 4 | 3 | 2 | 1 | `4 3 2 1` |

- `range(4, 0, -1)` → j가 4, 3, 2, 1 순서로 역순 반복
- `j <= i`이면 숫자 출력, 아니면 공백 출력
- 결과적으로 오른쪽 정렬된 역삼각형 패턴이 출력됨

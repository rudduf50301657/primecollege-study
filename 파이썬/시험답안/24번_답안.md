# 파이썬 시험 24번 답안

## 문제

가변 파라미터에 대한 설명으로 옳은 것은?

## 답: ②

**개수가 정해지지 않는 여러 개의 인자를 받을 수 있게 한다.**

## 풀이

가변 파라미터는 `*args`(위치 인자)나 `**kwargs`(키워드 인자)로 정의하여 개수 제한 없이 인자를 받을 수 있다.

```python
def my_sum(*args):
    return sum(args)

my_sum(1, 2, 3)      # 6
my_sum(1, 2, 3, 4, 5) # 15
```

- ① 항상 하나의 인자만 받음 → 여러 개 가능
- ③ 반환값을 가질 수 없다 → 반환값과 무관
- ④ 파이썬에서 사용 불가 → *args, **kwargs로 사용 가능

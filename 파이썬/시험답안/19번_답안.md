# 파이썬 시험 19번 답안

## 문제

```python
message1 = "파이썬을 "
message2 = message1 + "잘 합니다."
message3 = message2 + "즐겨!" * 2
print(message3)
```

## 답: ③ 파이썬을 잘 합니다.즐겨!즐겨!

## 풀이

1. message1 = "파이썬을 "
2. message2 = "파이썬을 " + "잘 합니다." = "파이썬을 잘 합니다."
3. "즐겨!" * 2 = "즐겨!즐겨!" (문자열 반복)
4. message3 = "파이썬을 잘 합니다." + "즐겨!즐겨!" = "파이썬을 잘 합니다.즐겨!즐겨!"

# 파이썬 시험 1번 답안

## 문제

다음 중 변수의 이름으로 가장 적절한 것은?

## 답: ③ total_score

## 풀이

| 선지 | 사용 가능 여부 | 이유 |
|------|-------------|------|
| ① 1score | 불가 | 숫자로 시작하는 변수명은 사용할 수 없다 |
| ② if | 불가 | 파이썬 예약어(키워드)이므로 변수명으로 사용할 수 없다 |
| ③ total_score | **가능** | 영문자와 언더스코어로 구성된 적절한 변수명 |
| ④ a+b | 불가 | 연산자(+)가 포함되어 변수명으로 사용할 수 없다 |

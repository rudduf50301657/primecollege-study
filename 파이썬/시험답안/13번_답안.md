# 파이썬 시험 13번 답안

## 문제

```python
banned_set = {'free', 'money', 'lucky', '행운', '바보', '성인'}

title = "Get it for FREE 바보!"
title = title.lower()
title = "".join(char for char in title if char.isalnum() or char == ' ')
words = title.split()
words_set = set(words)

if words_set & banned_set:
    print("스팸입니다.")
else:
    print("스팸이 아닙니다.")
```

## 답: ② 스팸입니다.

## 풀이

1. `title.lower()` → "get it for free 바보!"
2. `join(isalnum or 공백)` → "get it for free 바보" (느낌표 제거)
3. `split()` → ["get", "it", "for", "free", "바보"]
4. `set(words)` → {"get", "it", "for", "free", "바보"}
5. `words_set & banned_set` → {"free", "바보"} (교집합이 존재)
6. 교집합이 비어있지 않으므로 → "스팸입니다." 출력

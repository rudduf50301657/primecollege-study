## 배경

- 지난 강의에서 웹스크래핑을 통해 데이터를 수집하는 방법을 학습함
- 수집된 데이터에는 불필요한 기호, 특수문자 등 "쓰레기 데이터"가 많이 포함되어 있음
- GIGO(Garbage In, Garbage Out) 원칙에 따라, 깨끗한 데이터 없이는 좋은 분석 결과를 얻을 수 없음
- 이번 강의에서는 데이터 정제 후 분석하여 의미 있는 정보를 추출하는 방법을 다룸

## 주요 내용

### 1. 텍스트 데이터 전처리 (Text Data Preprocessing)

| 단계 | 설명 |
|------|------|
| 특수문자 제거 | 이모티콘, 특수기호 등 분석에 불필요한 문자 제거 |
| 대소문자 통일 | 같은 단어가 대소문자 차이로 분리되는 것 방지 |
| HTML 태그 제거 | 웹 수집 데이터에 포함된 HTML 태그 정리 |
| 불용어 제거 | "아니", "근데" 등 분석에 불필요한 단어 제거 |

- **정규표현식(Regular Expression)**: `re` 표준 라이브러리를 사용하여 특정 패턴의 문자열을 탐색/제거
  - `[^A-Za-z0-9가-힣\s]` — 영문, 숫자, 한글, 공백 외 모든 문자 찾기
  - `<.*?>` — HTML 태그 매칭
  - `\s+` — 연속 공백 문자 매칭
  - 주요 메소드: `match`, `search`, `findall`, `sub`

### 2. 형태소 분석 (Morphological Analysis)

- **Kiwi 라이브러리** 사용 (KoNLPy보다 최근에 많이 사용됨)
- 한국어는 영어와 달리 교착어로, 명사 뒤에 조사, 동사 뒤에 어미가 붙어 분석이 복잡함
- Kiwi를 통해 품사를 파악하고, 원하는 품사(NNG: 일반명사, NNP: 고유명사)만 추출
- `add_user_word()`로 사용자 정의 단어(예: "방송대") 등록 가능

### 3. 텍스트 데이터 분석

- **키워드 분석**: `collections.Counter` 클래스를 사용하여 단어 출현 빈도 분석
  - `most_common(30)` — 상위 30개 빈출 단어 추출
- **분석 결과 예시** (방송대 공지사항 게시판):
  - 안내(93회), 학년도(73회), 학기(65회), 수강(43회), 신청(43회) 등
  - 수강, 증명서 발급, 모집, 등록금, 학점인정, 시험 관련 학사 안내가 주요 내용

### 4. 시각화 — 워드클라우드(WordCloud)

- `wordcloud` 라이브러리 + `matplotlib` 연동
- 설정: 그래프 크기(800x480), 배경색(white), 컬러맵(viridis)
- 한글 폰트 설치 필수 (Google Colab 환경)
- 출현 빈도에 따라 글자 크기와 색상이 차별화되어 직관적으로 데이터 패턴 파악 가능

## 핵심 정리

- **텍스트 데이터 전처리**: 정규표현식을 활용하여 특수문자, 기호 등 불필요한 요소를 제거하고 분석에 적합한 형태로 정제하는 기술

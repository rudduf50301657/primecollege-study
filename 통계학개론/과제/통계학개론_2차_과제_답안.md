### R 코드

```r
# TeachingDemos 패키지 설치(대소문자 유의)
install.packages("TeachingDemos")
library(TeachingDemos)

# 표본 수가 2일 때, 표본평균의 분포
clt.examp(2)
# 표본 수가 5일 때, 표본평균의 분포
clt.examp(5)
# 표본 수가 10일 때, 표본평균의 분포
clt.examp(10)
# 표본 수가 30일 때, 표본평균의 분포
clt.examp(30)
```

### 결과에 대한 해석

`clt.examp()` 함수는 모집단의 분포가 정규분포, 감마분포, 균등분포, 베타분포일 때 각각의 표본평균 분포를 시각적으로 보여주는 함수이다.

**1) 표본평균의 분포 특징**

- **n = 2일 때**: 표본 수가 매우 적으므로, 표본평균의 분포는 원래 모집단의 분포 형태를 상당 부분 유지한다. 정규분포 모집단의 경우 정규분포에 가까우나, 감마분포나 베타분포처럼 비대칭인 모집단에서는 표본평균의 분포도 비대칭적인 형태를 보인다. 균등분포의 경우 삼각형에 가까운 형태가 나타난다.

- **n = 5일 때**: 표본 수가 증가함에 따라 표본평균의 분포가 점차 종모양(bell-shaped)에 가까워진다. 비대칭 분포(감마, 베타)에서도 약간의 비대칭성이 남아 있지만, n=2일 때보다 정규분포에 더 가까워진 것을 확인할 수 있다.

- **n = 10일 때**: 대부분의 모집단 분포에서 표본평균의 분포가 정규분포에 상당히 가까워진다. 감마분포와 같이 강한 비대칭 분포에서도 정규분포에 근접하는 경향을 보인다.

- **n = 30일 때**: 표본 수가 30 이상이 되면, 모집단의 원래 분포 형태(정규, 감마, 균등, 베타)에 관계없이 표본평균의 분포가 거의 완벽한 정규분포 형태를 나타낸다.

**2) 중심극한정리(CLT)에 의한 해석**

> **[강의록 근거]**
> - 7강 p.8 "표본평균의 기댓값과 분산": E(X̄) = μ, Var(X̄) = σ²/n
> - 7강 p.9 "표본평균의 분포(정규모집단의 경우)": 모집단이 N(μ, σ²)이면 X̄ ~ N(μ, σ²/n)
> - 7강 p.10 "중심극한정리(Central Limit Theorem)": 평균이 μ이고 분산이 σ²인 **임의의** 모집단에서 표본 크기 n이 충분히 크면, X̄ ~ N(μ, σ²/n), (X̄ - μ)/(σ/√n) ~ N(0, 1)
> - 7강 p.12 "이항분포의 정규근사 예시": n=2, 5, 10, 25로 증가할수록 분포가 정규분포에 근사하는 히스토그램 시각화

이 결과는 **중심극한정리**가 실제로 성립하는 것을 눈으로 확인할 수 있게 보여준다. 중심극한정리에 따르면(7강 p.10), 모집단의 분포가 정규분포이든 감마분포이든 균등분포이든 베타분포이든 어떤 형태이든 간에, 표본의 크기가 충분히 크면 표본평균의 분포는 모집단의 원래 분포 형태에 관계없이 근사적으로 정규분포를 따르게 된다.

또한 표본평균의 기댓값은 모평균과 같고, 표본평균의 분산은 모분산을 표본 크기로 나눈 값이므로(7강 p.8), 표본 크기가 커질수록 표본평균의 분산이 작아져서 분포가 모평균 주위로 더 좁게 집중되는 것을 확인할 수 있다. 이는 표본 크기가 클수록 표본평균이 모평균에 더 가까운 값을 가질 가능성이 높아진다는 것을 의미한다.

## 문제2. [8강. 통계적 추정 I - 모평균의 구간 추정] (25점)

> 조건: n = 100, 표본평균 X̄ = 75(만원), 표본표준편차 S = 5(만원), 모집단은 정규분포

### (1) 95% 신뢰도로 구간추정 (t분포 vs 정규분포)

#### R 코드

```r
# 95% 신뢰구간
# t 분포 이용, 표본 수 100
c(75 + qt(0.025, 99) * 5/sqrt(100), 75 + qt(0.975, 99) * 5/sqrt(100))
# 정규분포 이용
c(75 + qnorm(0.025) * 5/sqrt(100), 75 + qnorm(0.975) * 5/sqrt(100))
```

#### R 실행 결과

```
> c(75 + qt(0.025, 99) * 5/sqrt(100), 75 + qt(0.975, 99) * 5/sqrt(100))
[1] 74.00789 75.99211

> c(75 + qnorm(0.025) * 5/sqrt(100), 75 + qnorm(0.975) * 5/sqrt(100))
[1] 74.02002 75.97998
```

#### 결과에 대한 해석

> **[강의록 근거]**
> - 8강 p.20 "모평균의 신뢰구간" (σ 알 때 - 정규분포): [X̄ - z(α/2) · σ/√n, X̄ + z(α/2) · σ/√n]
> - 8강 p.21 "모평균의 신뢰구간" (σ 모를 때 - t분포): √n(X̄ - μ)/S ~ t(n-1)
> - 8강 p.22 "모평균의 신뢰구간" (t분포 공식): [X̄ - t(n-1, α/2) · S/√n, X̄ + t(n-1, α/2) · S/√n]
> - 8강 p.23 "신뢰수준과 신뢰구간": 표본수 증가하면 t(n-1, α/2)가 z(α/2)에 근접
> - 8강 p.18~19 "모평균의 신뢰구간": 95%는 ±1.96, 99%는 ±2.575 (정규분포 기준)

- **t분포를 이용한 95% 신뢰구간**: [74.00789, 75.99211] (구간 너비: 1.98422만원)
- **정규분포를 이용한 95% 신뢰구간**: [74.02002, 75.97998] (구간 너비: 1.95996만원)

t분포를 이용한 것과 정규분포를 이용한 것에 **실질적인 차이가 거의 없다.** 실제로 두 신뢰구간의 너비를 비교하면 t분포는 1.98422만원, 정규분포는 1.95996만원으로 그 차이가 매우 작다. 그 이유는 표본 크기 n = 100으로 충분히 크기 때문이다. 8강 p.23에서 배운 대로, 표본 수가 증가하면 t분포가 표준정규분포에 가까워지므로, 표본 크기가 100처럼 큰 경우에는 두 방법으로 구한 신뢰구간이 거의 동일하게 나오는 것이다.

다만 이론적으로는, 이 문제에서 모분산을 모르고 표본표준편차를 사용하였으므로(8강 p.21~22) **t분포를 이용하는 것이 더 정확한 방법**이다.

### (2) 99% 신뢰도로 구간추정

#### R 코드

```r
# 99% 신뢰구간
# t 분포 이용, 표본 수 100
c(75 + qt(0.005, 99) * 5/sqrt(100), 75 + qt(0.995, 99) * 5/sqrt(100))
```

#### R 실행 결과

```
> c(75 + qt(0.005, 99) * 5/sqrt(100), 75 + qt(0.995, 99) * 5/sqrt(100))
[1] 73.68680 76.31320
```

#### 결과에 대한 해석

> **[강의록 근거]**
> - 8강 p.23 "신뢰수준과 신뢰구간": 신뢰수준이 클수록 신뢰구간에 모평균 포함될 가능성 증가
> - 8강 p.18 "모평균의 신뢰구간": 95%는 ±1.96, 99%는 ±2.575 → 신뢰수준이 높을수록 임계값이 커져 구간이 넓어짐

- **99% 신뢰구간**: [73.68680, 76.31320] (구간 너비: 2.62640만원)
- **95% 신뢰구간(문제 (1))**: [74.00789, 75.99211] (구간 너비: 1.98422만원)

99% 신뢰구간의 너비(2.62640만원)가 95% 신뢰구간의 너비(1.98422만원)보다 **더 넓다.** 8강 p.23에서 배운 대로, 신뢰수준이 클수록 신뢰구간에 모평균이 포함될 가능성이 증가하므로 그만큼 구간의 범위가 넓어진다. 8강 p.18의 그래프에서도 95%는 ±1.96, 99%는 ±2.575로 신뢰수준이 높을수록 임계값이 커지는 것을 확인할 수 있다.

### (3) 표본크기 400명일 때 95% 신뢰구간

#### R 코드

```r
# 95% 신뢰구간
# t 분포 이용, 표본 수 400
c(75 + qt(0.025, 399) * 5/sqrt(400), 75 + qt(0.975, 399) * 5/sqrt(400))
```

#### R 실행 결과

```
> c(75 + qt(0.025, 399) * 5/sqrt(400), 75 + qt(0.975, 399) * 5/sqrt(400))
[1] 74.50852 75.49148
```

#### 결과에 대한 해석

> **[강의록 근거]**
> - 7강 p.8 "표본평균의 기댓값과 분산": Var(X̄) = σ²/n → n이 커지면 분산이 줄어듦
> - 8강 p.22 구간추정 공식: [X̄ - t(n-1, α/2) · S/√n, X̄ + t(n-1, α/2) · S/√n] → 구간 너비가 S/√n에 비례
> - 8강 p.30 "정리하기": 구간추정은 모수를 포함할 것으로 기대되는 구간을 제시하여 모수를 추정하는 것

- **n=400일 때 95% 신뢰구간**: [74.50852, 75.49148] (구간 너비: 0.98296만원)
- **n=100일 때 95% 신뢰구간(문제 (1))**: [74.00789, 75.99211] (구간 너비: 1.98422만원)

표본크기를 100명에서 400명으로 4배 늘렸을 때, 95% 신뢰구간의 너비가 1.98422만원에서 0.98296만원으로 약 **절반**으로 줄어들었다. 8강 p.22의 구간추정 공식에서 신뢰구간의 너비는 S/√n에 비례하고, 7강 p.8에서 배운 대로 Var(X̄) = σ²/n이므로 표본크기가 4배(100→400)가 되면 √n이 2배(10→20)가 되어 구간의 너비는 약 1/2로 줄어든다. 즉, 표본크기가 커질수록 표본평균의 변동이 줄어들어 모평균을 더 정밀하게 추정할 수 있다.

## 문제3. [10강. 통계적 가설검정 I - 모평균에 대한 가설검정] (25점)

> 조건: n = 10, 표본평균 X̄ = 12.2, 표본표준편차 S = 0.2, 모집단은 정규분포, "12회보다 큰지" 검정

### (1) 귀무가설과 대립가설

> **[강의록 근거]**
> - 10강 p.10~11 "가설검정의 오류": H₀ 참으로 두고, 근거 확실 않다면 H₀ 기각하지 않음
> - 10강 p.20~26 "모평균의 가설검정 예": 전기차 1회 충전 거리 500km 예제에서 H₀: μ = 500, H₁: μ > 500으로 설정하는 단측검정 사례

- **귀무가설(H₀)**: μ = 12 (전체 가구의 평균 은행방문횟수는 12회이다)
- **대립가설(H₁)**: μ > 12 (전체 가구의 평균 은행방문횟수는 12회보다 크다)

문제에서 평균 은행방문횟수가 "12회보다 큰지"를 검정하고자 하므로, 10강의 전기차 예제(p.20)와 같은 구조로 대립가설을 단측(우측) 가설로 설정한다.

### (2) 검정통계량 T

#### R 코드

```r
# 모평균에 대한 검정
mu = 12 ; barX = 12.2
S = 0.2 ; n = 10 ; alpha = 0.05

# t 통계량값
T = (12.2 - 12) / (0.2 / sqrt(10))
T
```

#### R 실행 결과

```
> T = (12.2 - 12) / (0.2 / sqrt(10))
> T
[1] 3.162278
```

#### 해석

> **[강의록 근거]**
> - 10강 p.21 "모평균 검정 관련 검정통계량": σ 모를 때 T = (X̄ - μ₀)/(S/√n) ~ t(n-1)

검정통계량 T는 10강 p.21에서 배운 공식 T = (X̄ - μ₀) / (S/√n)을 사용하여 계산한다. 모표준편차 σ를 모르므로 표본표준편차 S를 사용하며, 이 검정통계량은 자유도 n-1 = 9인 t분포를 따른다. T = (12.2 - 12) / (0.2/√10) = 0.2 / 0.0632 = **3.1623**이다.

### (3) 유의수준 0.05에서 기각여부와 결론

#### R 코드

```r
# 유의확률: 단측검정
PV = 1 - pt(T, 9)
PV
if (PV < alpha) print("5% 유의수준에서 귀무가설 기각")
if (PV >= alpha) print("5% 유의수준에서 귀무가설 기각하지 못함")
```

#### R 실행 결과

```
> PV = 1 - pt(T, 9)
> PV
[1] 0.005754
> if (PV < alpha) print("5% 유의수준에서 귀무가설 기각")
[1] "5% 유의수준에서 귀무가설 기각"
```

#### 결과에 대한 해석

> **[강의록 근거]**
> - 10강 p.22~23 "모평균의 가설검정 예 - 검정 통계량의 분포와 기각역": 우측 단측검정에서 T가 기각역(rejection region)에 속하면 H₀ 기각
> - 10강 p.10~11 "가설검정의 오류": 유의확률이 유의수준보다 작으면 H₀을 기각

유의확률(p-value)은 0.0058로 유의수준 alpha = 0.05보다 작다. 따라서 **귀무가설을 기각**한다.

또한 기각역을 이용하여 판단하면(10강 p.22), 우측 단측검정의 기각역은 T > t(9, 0.05) = 1.8331인데, 검정통계량 T = 3.1623 > 1.8331이므로 기각역에 속한다.

**결론**: 유의수준 5%에서 귀무가설을 기각하고 대립가설을 채택한다. 즉, 이 아파트 한 동의 가구들에 대해 조사한 결과, 우리나라 전체 가구의 평균 은행방문횟수가 12회보다 크다고 판단할 수 있는 통계적 근거가 충분하다.

## 문제4. [12강. 통계적 비교 I - 대응 표본에 대한 두 모집단 평균의 비교] (25점)

> 조건: 대응표본(같은 연주에 대해 두 평가자가 평가), n = 10, 유의수준 5%, 차이의 정규분포 가정

### R 코드

```r
# 두 평가자의 데이터 수집
x = c(90, 80, 75, 60, 65, 70, 95, 90, 88, 50)
y = c(88, 84, 72, 65, 68, 76, 96, 93, 90, 60)

# t 검정, 짝진 두 모집단 평균 검정
it = t.test(x, y, paired = TRUE)
it
```

### 결과에 대한 해석

> **[강의록 근거]**
> - 12강 p.9 "대응표본 시 두 모집단의 비교": 짝지어진 n쌍(pair)의 표본 차이를 계산하여 단일표본의 검정문제로 단순화. D_i = X_i1 - X_i2, D̄ = ΣD_i/n, s²_D = Σ(D_i - D̄)²/(n-1)
> - 12강 p.10 "대응표본 시 두 모집단의 비교" 가설별 선택기준 표:
>   - ③ H₀: μ₁ - μ₂ = D₀, H₁: μ₁ - μ₂ ≠ D₀ → |(D̄ - D₀)/(s_D/√n)| > t(n-1, α/2)이면 H₀ 기각

**1) 가설 설정**

- 귀무가설(H₀): μ₁ - μ₂ = 0 (두 평가자 간 평가에 차이가 없다)
- 대립가설(H₁): μ₁ - μ₂ ≠ 0 (두 평가자 간 평가에 차이가 있다)

문제에서 "차이가 있는지"를 검정하므로 12강 p.10의 ③번 형태(양측검정)를 수행한다.

**2) 대응표본 분석**

12강 p.9에서 배운 대로, 대응표본(paired sample)의 경우 각 쌍의 차이 D_i = X_i1 - X_i2를 구하여 단일 표본의 검정 문제로 단순화한다.

- 차이(D): 2, -4, 3, -5, -3, -6, -1, -3, -2, -10
- 차이의 평균(D̄ = ΣD_i/n): -2.9
- 차이의 표준편차(s_D = √[Σ(D_i - D̄)²/(n-1)]): 3.7845

검정통계량(12강 p.10): T = (D̄ - D₀) / (s_D/√n) = (-2.9 - 0) / (3.7845/√10) = **-2.4232** (자유도 df = 9)

**3) 검정 결과 및 결론**

유의확률(p-value) = 0.03841로, 유의수준 alpha = 0.05보다 작으므로 **귀무가설을 기각**한다.

12강 p.10의 선택기준 ③에 따라 |T| = 2.4232 > t(9, 0.025) = 2.2622이므로 기각역에 속하여 H₀을 기각한다.

**결론**: 유의수준 5%에서 귀무가설을 기각하고 대립가설을 채택한다. 즉, 두 평가자 간 평가에는 통계적으로 유의한 차이가 있다고 판단할 수 있다. 차이의 평균이 -2.9로 음수이므로, 평가자2가 평가자1보다 평균적으로 약 2.9점 높게 평가하는 경향이 있다.

## 문제1 - 제출용 해석

clt.examp() 함수는 모집단의 분포가 정규분포, 감마분포, 균등분포, 베타분포일 때 각각의 표본평균 분포를 시각적으로 보여주는 함수이다.

1) 표본평균의 분포 특징

- n = 2일 때: 표본 수가 매우 적으므로, 표본평균의 분포는 원래 모집단의 분포 형태를 상당 부분 유지한다. 정규분포 모집단의 경우 정규분포에 가까우나, 감마분포나 베타분포처럼 비대칭인 모집단에서는 표본평균의 분포도 비대칭적인 형태를 보인다. 균등분포의 경우 삼각형에 가까운 형태가 나타난다.

- n = 5일 때: 표본 수가 증가함에 따라 표본평균의 분포가 점차 종모양(bell-shaped)에 가까워진다. 비대칭 분포(감마, 베타)에서도 약간의 비대칭성이 남아 있지만, n=2일 때보다 정규분포에 더 가까워진 것을 확인할 수 있다.

- n = 10일 때: 대부분의 모집단 분포에서 표본평균의 분포가 정규분포에 상당히 가까워진다. 감마분포와 같이 강한 비대칭 분포에서도 정규분포에 근접하는 경향을 보인다.

- n = 30일 때: 표본 수가 30 이상이 되면, 모집단의 원래 분포 형태(정규, 감마, 균등, 베타)에 관계없이 표본평균의 분포가 거의 완벽한 정규분포 형태를 나타낸다.

2) 중심극한정리에 의한 해석

이 결과는 중심극한정리가 실제로 성립하는 것을 눈으로 확인할 수 있게 보여준다. 중심극한정리에 따르면, 모집단의 분포가 정규분포이든 감마분포이든 균등분포이든 베타분포이든 어떤 형태이든 간에, 표본의 크기가 충분히 크면 표본평균의 분포는 모집단의 원래 분포 형태에 관계없이 근사적으로 정규분포를 따르게 된다.

또한 표본평균의 기댓값은 모평균과 같고, 표본평균의 분산은 모분산을 표본 크기로 나눈 값이므로, 표본 크기가 커질수록 표본평균의 분산이 작아져서 분포가 모평균 주위로 더 좁게 집중되는 것을 확인할 수 있다. 이는 표본 크기가 클수록 표본평균이 모평균에 더 가까운 값을 가질 가능성이 높아진다는 것을 의미한다.

## 문제2(1) - 제출용 해석

- t분포를 이용한 95% 신뢰구간: [74.00789, 75.99211] (구간 너비: 1.98422만원)
- 정규분포를 이용한 95% 신뢰구간: [74.02002, 75.97998] (구간 너비: 1.95996만원)

t분포를 이용한 것과 정규분포를 이용한 것에 실질적인 차이가 거의 없다. 실제로 두 신뢰구간의 너비를 비교하면 t분포는 1.98422만원, 정규분포는 1.95996만원으로 그 차이가 매우 작다. 그 이유는 표본 크기 n = 100으로 충분히 크기 때문이다. 표본 수가 증가하면 t분포가 표준정규분포에 가까워지므로, 표본 크기가 100처럼 큰 경우에는 두 방법으로 구한 신뢰구간이 거의 동일하게 나오는 것이다.

다만 이론적으로는, 이 문제에서 모분산을 모르고 표본표준편차를 사용하였으므로 t분포를 이용하는 것이 더 정확한 방법이다.

## 문제2(2) - 제출용 해석

- 99% 신뢰구간: [73.68680, 76.31320] (구간 너비: 2.62640만원)
- 95% 신뢰구간(문제 (1)): [74.00789, 75.99211] (구간 너비: 1.98422만원)

99% 신뢰구간의 너비(2.62640만원)가 95% 신뢰구간의 너비(1.98422만원)보다 더 넓다. 이는 신뢰수준이 높아질수록 모평균이 구간 안에 포함될 확률을 더 크게 보장해야 하므로, 그만큼 구간의 범위가 넓어지기 때문이다. 즉, 신뢰수준이 높아지면 임계값이 커지고, 그에 따라 신뢰구간의 너비도 넓어지는 것이다.

## 문제2(3) - 제출용 해석

- n=400일 때 95% 신뢰구간: [74.50852, 75.49148] (구간 너비: 0.98296만원)
- n=100일 때 95% 신뢰구간(문제 (1)): [74.00789, 75.99211] (구간 너비: 1.98422만원)

표본크기를 100명에서 400명으로 4배 늘렸을 때, 95% 신뢰구간의 너비가 1.98422만원에서 0.98296만원으로 약 절반으로 줄어들었다. 이는 신뢰구간의 너비가 표본표준편차를 표본 크기의 제곱근으로 나눈 값(S/√n)에 비례하기 때문이다. 표본크기가 4배(100→400)가 되면 제곱근이 2배(10→20)가 되므로, 구간의 너비는 약 1/2로 줄어든다. 즉, 표본크기가 커질수록 표본평균의 변동이 줄어들어 모평균을 더 정밀하게 추정할 수 있다.

## 문제3(1) - 제출용 해석

- 귀무가설(H0): 전체 가구(모집단)의 모평균 은행방문횟수는 12회이다.
- 대립가설(H1): 전체 가구(모집단)의 모평균 은행방문횟수는 12회보다 크다.

문제에서 평균 은행방문횟수가 "12회보다 큰지"를 검정하고자 하므로, 대립가설은 단측(우측) 가설로 설정한다.

## 문제3(2) - 제출용 해석

R 코드에서 mu = 12는 귀무가설에서의 모평균, barX = 12.2는 표본평균, S = 0.2는 표본표준편차, n = 10은 표본 크기, alpha = 0.05는 유의수준을 의미한다. 검정통계량 T는 표본평균에서 모평균을 뺀 값(12.2 - 12 = 0.2)을, 표본표준편차를 표본 크기의 제곱근으로 나눈 표준오차(0.2 / sqrt(10) = 0.0632)로 나누어 계산한다. 모표준편차를 모르므로 표본표준편차를 사용하며, 이 검정통계량은 자유도 9(= 10 - 1)인 t분포를 따른다. 계산하면 T = 0.2 / 0.0632 = 3.1623이다.

## 문제3(3) - 제출용 해석

유의확률(p-value)은 0.005754로 유의수준 alpha = 0.05보다 작다. 따라서 귀무가설을 기각한다.

또한 기각역을 이용하여 판단하면, 우측 단측검정의 기각역은 T > t(9, 0.05) = 1.8331인데, 검정통계량 T = 3.1623 > 1.8331이므로 기각역에 속한다.

결론: 유의수준 5%에서 귀무가설을 기각하고 대립가설을 채택한다. 즉, 이 아파트 한 동의 가구들에 대해 조사한 결과, 우리나라 전체 가구의 평균 은행방문횟수가 12회보다 크다고 판단할 수 있는 통계적 근거가 충분하다.

## 문제4 - 제출용 해석

1) 가설 설정

- 귀무가설(H0): 두 평가자 간 평가에 차이가 없다.
- 대립가설(H1): 두 평가자 간 평가에 차이가 있다.

문제에서 "차이가 있는지"를 검정하므로 양측검정을 수행한다.

2) 대응표본 분석

이 문제는 같은 연주에 대해 두 평가자가 각각 평가한 것이므로 대응표본(paired sample)에 해당한다. 대응표본의 경우 각 쌍의 차이를 구하여 단일 표본의 검정 문제로 단순화한다.

R 실행 결과를 보면, 검정통계량 t = -2.4232, 자유도 df = 9, 차이의 평균은 -2.9로 나타났다.

3) 검정 결과 및 결론

유의확률(p-value)은 0.03841로, 유의수준 0.05보다 작으므로 귀무가설을 기각한다.

결론: 유의수준 5%에서 귀무가설을 기각하고 대립가설을 채택한다. 즉, 두 평가자 간 평가에는 통계적으로 유의한 차이가 있다고 판단할 수 있다. 차이의 평균이 -2.9로 음수이므로, 평가자2가 평가자1보다 평균적으로 약 2.9점 높게 평가하는 경향이 있다.

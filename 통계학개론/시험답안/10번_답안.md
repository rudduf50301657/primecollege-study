# 통계학개론 시험 10번 답안

## 문제 (배점 4점)

P(A) = 0.3 이고, P(A|B) = 0.3 이라고 할 때, 가)~라) 중 옳은 것을 모두 고르면?

## 답: ④ 가, 다, 라

## 풀이

P(A|B) = P(A) = 0.3 이므로 → **A와 B는 독립사건**

| 선지 | 내용 | 판단 |
|------|------|------|
| 가) | 사건 A와 B는 서로 독립사건이다 | **맞음** ✓ — P(A|B) = P(A)이므로 독립 |
| 나) | 사건 A와 B는 서로 배반사건이다 | **틀림** ✗ — 독립 ≠ 배반. 독립이면 P(A∩B) = P(A)P(B) ≠ 0 |
| 다) | P(B) = P(B\|A) 이다 | **맞음** ✓ — 독립이면 P(B\|A) = P(B) 성립 |
| 라) | P(A∩B) = P(A)P(B\|A) 이다 | **맞음** ✓ — 조건부확률의 곱셈법칙으로 항상 성립 |

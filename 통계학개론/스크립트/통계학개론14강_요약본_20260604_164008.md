## 주요 논의 사항

### 1. 상관계수 (Correlation Coefficient)

| 항목 | 내용 |
|------|------|
| 정의 | 두 연속형 변수 간 **선형 관계의 강도**를 나타내는 수치적 척도 |
| 범위 | -1 ≤ r ≤ 1 |
| r = 1 | 완벽한 양의 직선 관계 (양의 기울기) |
| r = -1 | 완벽한 음의 직선 관계 (음의 기울기) |
| r = 0 | 선형 관계 없음 (비선형 관계가 있을 수 있음) |

- **산점도(Scatter Plot)**: 두 연속형 변수의 관계를 시각적으로 확인하는 도구
- **표본 공분산(Sample Covariance)**: xi와 yi의 평균으로부터의 차이를 곱하여 합산한 값, 방향성을 나타냄
- **표본 상관계수**: 표본 공분산을 각각의 표준편차로 나누어 **표준화**한 것
- 핵심: 상관계수는 **선형(직선) 관계**만을 측정하며, 곡선 관계나 원형 관계는 r ≈ 0이 될 수 있음

### 2. 단순 선형 회귀모형 (Simple Linear Regression)

- **회귀분석**: 변수 간 **함수적 관련성**을 규명하는 분석 방법
- **"단순"**: 독립변수가 하나 (Simple)
- **"선형"**: 직선 형태의 관계식 (Linear)
- 모형: **yi = α + βxi + εi**
  - α: 절편 (intercept), β: 기울기 (slope) → 회귀계수
  - xi: 독립변수(설명변수, 입력변수)
  - yi: 종속변수(반응변수, 출력변수)
  - εi: 오차항

- **오차항의 가정 (i.i.d.)**: εi는 서로 독립이고, 평균 0, 분산 σ²인 동일한 분포를 따름

### 3. 최소제곱법 (Least Squares Method)

- 목적: 잔차제곱합(RSS)을 최소화하는 회귀계수 a, b를 찾는 것
- 잔차(Residual): 적합된 회귀직선과 실제 관측치 사이의 편차
- 편미분을 통해 a, b 도출:
  - b(기울기): 공분산과 유사한 형태 → 상관계수 r과 밀접한 관계
  - a(절편): ȳ - b·x̄

### 4. 결정계수 (R²)

- **R² = SSR / SST** (회귀직선에 의한 변동 / 총변동)
- 총변동(SST) = 회귀변동(SSR) + 잔차변동(SSE)
- R²가 1에 가까울수록 회귀직선의 설명력이 높음

### 5. 분산분석표 (ANOVA)와 회귀모형 검정

| 요인 | 제곱합 | 자유도 | 평균제곱합 |
|------|--------|--------|------------|
| 회귀 | SSR | 1 | MSR = SSR/1 |
| 잔차 | SSE | n-2 | MSE = SSE/(n-2) |
| 총계 | SST | n-1 | - |

- F검정: F₀ = MSR / MSE
- 귀무가설: β = 0 (직선 관계가 의미 없음)
- F₀가 임계치를 초과하면 귀무가설 기각 → 회귀모형이 유의미함

### 6. 회귀계수의 추론

- b의 분포: N(β, σ²/Sxx) → 정규분포를 따름
- β의 신뢰구간: b ± t(α/2, n-2) × SE(b)
- β의 t검정: t₀ = (b - β₀) / SE(b)
  - β₀ = 0으로 놓으면 분산분석의 F검정과 동일한 결과

## 합의 사항

- 상관계수는 반드시 **선형 관계**를 의미하며, 일반적인 관계를 의미하지 않음
- 회귀모형의 수리적 유도(편미분 등)보다 **수치적 의미와 해석**에 집중할 것

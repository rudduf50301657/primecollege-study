## 배경

- 이번 강의에서는 수치형 반응값이 아닌 **범주형 데이터(도수)**를 기반으로 한 분석 방법을 소개
- 분할표(Contingency Table)를 작성하고 카이제곱(χ²) 통계량을 활용한 검정 방법을 학습

## 주요 논의 사항

### 1. 범주형 데이터와 분할표

- **범주형 데이터(Categorical Data)**: 명확하게 구분되는 범주(category)에 따른 도수(frequency) 데이터
- **분할표**: 범주를 정하고 각 범주에 도수를 기입하여 데이터 분포를 나타내는 표
- **1원 분할표**: 변수 1개 (예: 과목명별 등록생 수)
- **2원 분할표**: 변수 2개 (예: 학과 × 등록 여부)
- 기존 분산분석과의 차이: 분산분석은 수치형 반응값을 다루지만, 분할표 검정은 **도수(빈도)**를 다룸

### 2. 독립성 검정 (Test of Independence)

| 항목 | 내용 |
|------|------|
| 목적 | 두 변수(요인) A, B가 서로 독립인지 검정 |
| 귀무가설 H₀ | 변수 A와 B는 독립이다 (P(A∩B) = P(A)·P(B)) |
| 대립가설 H₁ | 변수 A와 B는 독립이 아니다 |
| 기대값 계산 | E = (행의 합 × 열의 합) / N |
| 자유도 | (r-1) × (c-1) (r: 행 수, c: 열 수) |

- **카이제곱 통계량**: χ² = Σ (O - E)² / E
  - O: 관측 도수, E: 기대 도수
  - χ² 값이 크면 → 기대값과 관측값의 괴리가 큼 → 독립이 아님을 시사
- **기대도수 5 이상 조건**: 기대도수가 5 미만인 셀은 인접 범주와 병합하여 계산

### 3. 적합도 검정 (Goodness of Fit Test)

| 항목 | 내용 |
|------|------|
| 목적 | 관측 데이터가 특정 이론적 분포를 따르는지 검정 |
| 귀무가설 H₀ | 데이터가 이론적 확률분포를 따른다 |
| 대립가설 H₁ | 이론적 확률분포를 따르지 않는다 |
| 기대값 계산 | E = n × P (n: 총 관측수, P: 이론적 확률) |
| 자유도 | k - p - 1 (k: 범주 수, p: 추정 모수 개수) |

- 독립성 검정과 동일한 카이제곱 통계량 사용
- 모수를 표본에서 추정한 경우 자유도에서 추정 모수 개수를 추가로 차감

### 4. R을 이용한 실습

- **독립성 검정**: `chisq.test(분할표, correct=FALSE)`
  - 예제: 학과(통계학과/데이터과학과) × 등록여부 → p-value = 0.3237 → H₀ 기각 불가 → 학과와 등록여부는 독립
  - `correct=FALSE`: 연속성 수정(Yates' correction) 미적용
- **적합도 검정**: `chisq.test(관측치, p=이론적확률)`
  - 예제: 60개 지점 부도수표 관측 → 포아송 분포 적합도 검정
  - 포아송 분포 모수(평균)를 표본평균으로 추정 → `dpois()` 함수로 이론적 확률 계산
  - 기대도수 < 5인 범주 병합 후 검정 → H₀ 기각 불가 → 포아송 분포를 따름

### 5. 카이제곱 분포의 이론적 배경

- 범주형 데이터는 다항분포를 따르며, 대표본에서 정규 근사 가능
- 정규분포의 제곱 → 카이제곱 분포로 연결
- 2×2 분할표에서는 **연속성 수정(continuity correction)** 적용 가능

## 합의 사항

- 카이제곱 통계량 공식: **χ² = Σ (O - E)² / E** — 반드시 숙지
- 독립성 검정과 적합도 검정은 데이터 형태는 다르나 검정 방법(카이제곱 통계량)은 동일
- 기대도수가 5 미만이면 인접 범주를 병합해야 함
- 교재의 손계산 과정을 직접 따라가 본 후 R로 검증할 것을 권장

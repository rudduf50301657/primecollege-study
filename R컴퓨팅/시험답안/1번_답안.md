## (2) X=1인 응시자 문제 (9점)

### 문제
행렬 A = (1, c; b, d) 에 대해 R에서 A%*%A 연산 결과가 (7, 6; 9, 10) 일 때, b+c-d 의 값을 구하라.

### 풀이과정 (배점의 70%)

A %*% A 는 행렬 곱셈이므로:

```
A %*% A = | 1*1+c*b   1*c+c*d |   =   | 1+bc    c(1+d) |
          | b*1+d*b   b*c+d*d |       | b(1+d)  bc+d²  |
```

이를 결과 행렬과 비교하면:

```
| 1+bc    c(1+d) |   =   | 7   6  |
| b(1+d)  bc+d²  |       | 9   10 |
```

**연립방정식:**
- ① 1 + bc = 7  →  bc = 6
- ② c(1+d) = 6
- ③ b(1+d) = 9
- ④ bc + d² = 10

**풀이:**
- ①에서 bc = 6, ④에서 bc + d² = 10 이므로 → d² = 4 → d = 2 (또는 -2)

**d = 2 일 때:**
- ②에서 c(1+2) = 6 → 3c = 6 → **c = 2**
- ③에서 b(1+2) = 9 → 3b = 9 → **b = 3**
- 검증: bc = 3×2 = 6 ✓

**d = -2 일 때:**
- ②에서 c(1-2) = 6 → -c = 6 → c = -6
- ③에서 b(1-2) = 9 → -b = 9 → b = -9
- 검증: bc = (-9)×(-6) = 54 ≠ 6 ✗ (탈락)

따라서 **b = 3, c = 2, d = 2**

### R 검증
```r
A <- matrix(c(1, 3, 2, 2), nrow = 2)
A
#      [,1] [,2]
# [1,]    1    2
# [2,]    3    2

A %*% A
#      [,1] [,2]
# [1,]    7    6
# [2,]    9   10
```

### 답안 (배점의 30%)

**b + c - d = 3 + 2 - 2 = 3**

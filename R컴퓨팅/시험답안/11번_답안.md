## 문제 (배점 5점)

```r
A <- matrix(c(1:4), ncol=2, byrow=T)
A[A[,(가)]>3, 1] * c(3,6)
[1] 9 18
```

(가)에 들어갈 수치(배점의 30%)와 그 이유(배점의 70%)를 서술하시오.

---

## 답: (가) = 2

---

## 풀이

### 행렬 A 구조

```r
A <- matrix(c(1:4), ncol=2, byrow=T)
#      [,1] [,2]
# [1,]   1    2
# [2,]   3    4
```

### (가) = 2일 때 연산 과정

1. `A[,2]` → 2열 값 추출 → `c(2, 4)`
2. `A[,2] > 3` → `c(2, 4) > 3` → `c(FALSE, TRUE)`
3. `A[c(FALSE, TRUE), 1]` → 조건이 TRUE인 2행의 1열 값 → `3`
4. `3 * c(3, 6)` → `c(9, 18)` ✓ (스칼라 재활용)

### 이유

`A <- matrix(c(1:4), ncol=2, byrow=T)`는 c(1,2,3,4)를 2열짜리 행렬로, 행 방향(byrow=T)으로 채운 것이므로 A는 다음과 같다.

```
     [,1] [,2]
[1,]   1    2
[2,]   3    4
```

(가)에 2를 넣으면 A[,2]는 2열의 값 c(2,4)이며, 이 중 3보다 큰 값은 4(2행)뿐이다. 따라서 조건을 만족하는 2행의 1열 값 3이 추출되고, 3 * c(3,6) = c(9,18)로 결과와 일치한다.

## 문제 (배점 10점)

다음은 기존 데이터 프레임과 tibble의 특징을 비교하여 나열한 것이다. 가장 옳지 **않은** 것은?

---

## 답: ②

---

## 각 선지 분석

| 선지 | 내용 | 판단 |
|------|------|------|
| ① | 기존 데이터 프레임은 모든 행과 열을 한꺼번에 출력, tibble은 화면에 맞게 일부만 출력하여 가독성 향상 | **옳음** ✓ |
| **②** | **기존 데이터 프레임은 각 열 아래에 자료형이 함께 표시되고, tibble은 속성 없이 간단히 출력된다** | **틀림** ✗ |
| ③ | 기존 데이터 프레임은 소규모에 적합, 대규모 데이터에는 tibble이 유리 | **옳음** ✓ |
| ④ | 기존 데이터 프레임은 열 이름이 자동 변환되지만, tibble은 입력한 열 이름 그대로 유지 | **옳음** ✓ |

### ②가 틀린 이유

실제로는 **반대**이다.
- **tibble**이 각 열 아래에 `<int>`, `<dbl>`, `<chr>` 등 자료형을 표시한다.
- **기존 데이터 프레임**은 자료형 표시 없이 값만 출력한다.

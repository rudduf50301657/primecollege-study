## 문제 (배점 5점)

score에 세 점수가 저장되어 있을 때, 60점 이상이면 "P", 60점 미만이면 "F"를 부여하도록 while문 내의 (가)에 적절한 명령문을 추가하시오.

```r
score = c(57, 88, 72)
grade = c(NA, NA, NA)
i = 1
while (i <= 3) {
  (가)
}
```

---

## 답

```r
grade[i] = ifelse(score[i] >= 60, "P", "F")
i = i + 1
```

---

## 풀이

### 완성된 코드

```r
score = c(57, 88, 72)
grade = c(NA, NA, NA)
i = 1
while (i <= 3) {
  grade[i] = ifelse(score[i] >= 60, "P", "F")
  i = i + 1
}
grade
# [1] "F" "P" "P"
```

### 실행 과정

| 반복 | i | score[i] | 60점 이상? | grade[i] |
|------|---|----------|----------|----------|
| 1회 | 1 | 57 | 미만 | "F" |
| 2회 | 2 | 88 | 이상 | "P" |
| 3회 | 3 | 72 | 이상 | "P" |

- `ifelse(조건, 참일 때 값, 거짓일 때 값)` 구조로 등급 부여
- `i = i + 1`로 인덱스를 증가시켜 다음 점수로 이동 (없으면 무한루프)

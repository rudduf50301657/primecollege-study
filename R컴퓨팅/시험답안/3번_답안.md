## 문제

반복문을 실행하여 구구단을 출력하는 R 명령문에서 "가"와 "나"에 들어갈 구문을 작성하시오.

```r
for( 가 ) {
  for( 나 ) {
    cat(i, "X", j, "=", i*j, "\n")
  }
}
```

---

## 답

- **가**: `i in 1:9`
- **나**: `j in 1:9`

---

## 완성된 코드

```r
for(i in 1:9) {
  for(j in 1:9) {
    cat(i, "X", j, "=", i*j, "\n")
  }
}
```

## 풀이

- 결과를 보면 i는 1~9, j는 1~9 범위로 반복
- 바깥 for문(가)에서 i가 1부터 9까지 순회
- 안쪽 for문(나)에서 j가 1부터 9까지 순회
- `cat()` 함수가 `i X j = i*j` 형태로 출력

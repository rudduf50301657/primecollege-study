## 문제 (배점 10점)

아래 <보기>와 같이 R을 실행하고 결과를 얻었다고 할 때, (가)에 들어갈 함수에 대한 설명으로 가장 적절한 것은?

```r
> a1 = c(1, 2, 3)
> a1[4] <- "K"
> (?)(a1)
[1] "character"
> a2 <- a1[-3]
> (?)(a2)
[1] "character"
```

---

## 답: ③

**mode 함수로서 벡터 a1과 벡터 a2 각각의 속성을 출력하는 함수이다.**

---

## 풀이

- `a1 = c(1, 2, 3)` → 숫자형 벡터
- `a1[4] <- "K"` → 문자 "K"가 추가되면서 벡터 전체가 문자형으로 강제 변환
- `mode(a1)` → `"character"` (벡터의 데이터 타입 출력)
- `a2 <- a1[-3]` → 3번째 원소 제거, 여전히 문자형 벡터
- `mode(a2)` → `"character"`

`mode()` 함수는 R 객체의 데이터 타입(속성)을 반환하는 함수이다.

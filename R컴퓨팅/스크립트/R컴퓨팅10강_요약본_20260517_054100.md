## 배경

- R 기본(base) 패키지에서 제공하는 그래픽 기능을 활용한 시각화 실습
- 별도 패키지 설치 없이도 구현 가능한 기본 그래프 학습
- 단일 변수(Univariate) 데이터의 분포, 중심 위치, 이상치 등을 시각적으로 파악

## 주요 논의 사항

### 1. 단일 변수 데이터 개념

- **개체(Observation)**: 관측 대상 (학생, 시간대, 상품 등)
- **변수(Variable)**: 개체마다 측정되는 하나의 특성 (키, 기온, 가격 등)
- **단일 변수**: 변수가 1개인 데이터 (vs 다변수: 키+몸무게+허리둘레 등)

### 2. 단일 변수 시각화의 목적

| 확인 사항 | 설명 |
|-----------|------|
| 분포(Distribution) | 값들이 어떻게 퍼져 있는지 |
| 중심 위치 | 평균, 중앙값의 위치 |
| 산포도 | 평균 주위로 얼마나 흩어져 있는지 |
| 치우침(Skewness) | 좌/우 한쪽으로 꼬리가 긴지 |
| 이상치(Outlier) | 전체 분포에서 동떨어진 관측값 |

### 3. 그래프 종류 및 R 함수

#### 막대 그림 (Bar Plot)
- 함수: `barplot(height, names, ...)`
- 용도: 범주별 크기 비교 (선호도, 빈도 등)
- 옵션: `beside`(나란히 배치), `legend`, `horiz`(수평), `col`(색상)
- 매개변수 없는 사용자 정의 함수로 실습 예제 구성

#### 원형 그림 (Pie Chart)
- 함수: `pie(x, labels, ...)`
- 용도: 전체 대비 각 범주의 비율 표현
- 옵션: `col`(색상), `main`(제목)

#### 히스토그램 (Histogram)
- 함수: `hist(x, breaks, ...)`
- 용도: 연속형 변수의 분포 확인 (구간별 빈도)
- 옵션: `breaks`(구간 수), `col`, `main`, `xlab`
- 분포의 모양(정규분포, 치우침)을 직관적으로 파악

#### 상자 그림 (Box Plot)
- 함수: `boxplot(x, ...)`
- 용도: 중앙값, 사분위수, 이상치를 한눈에 확인
- 구성요소:
  - 상자: Q1(25%) ~ Q3(75%) 범위 (IQR)
  - 중앙선: 중앙값(Median)
  - 수염(Whisker): Q1-1.5×IQR ~ Q3+1.5×IQR
  - 점: 이상치(Outlier)

### 4. 그래픽 레이아웃

- `par(mfrow=c(행, 열))`: 그래프 배치 공간 설정
  - `c(1,2)`: 1행 2열 (좌우 나란히)
  - `c(2,1)`: 2행 1열 (위아래)
  - `c(2,2)`: 2행 2열 (4분할)
- 함수 실행 순서대로 공간에 배치됨

### 5. 실습 예제

- 과일 선호도 데이터로 막대 그림/원형 그림 생성
- `rnorm()` 등으로 랜덤 데이터 생성 후 히스토그램 확인
- 상자 그림으로 이상치 탐지 실습
- 사용자 정의 함수(매개변수 없는 형태)로 그래프 코드를 묶어서 실행

## 핵심 정리

| 그래프 | 함수 | 적합한 데이터 | 주요 확인 사항 |
|--------|------|--------------|----------------|
| 막대 그림 | `barplot()` | 범주형 | 범주별 크기 비교 |
| 원형 그림 | `pie()` | 범주형 | 전체 대비 비율 |
| 히스토그램 | `hist()` | 연속형 | 분포 모양, 치우침 |
| 상자 그림 | `boxplot()` | 연속형 | 중앙값, IQR, 이상치 |

## 참고 사항

- R base 그래픽은 추가 패키지 없이 바로 사용 가능
- 향후 ggplot2 등 고급 시각화 패키지로 확장 가능
- `par()` 함수로 그래프 레이아웃을 사전에 설정하는 습관 권장

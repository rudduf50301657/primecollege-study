## 주요 내용

### 1. 다중 패널 그래프 (Facet)

단순히 화면을 분할하는 것이 아니라 동일한 축·스케일을 공유하면서 범주별로 의미 있는 비교가 가능한 그래프.

| 함수 | 설명 |
|------|------|
| `facet_wrap(~변수, nrow=, ncol=)` | 한 범주형 변수 기준으로 패널 분할. `nrow`/`ncol`로 배치 지정 |
| `facet_grid(행변수 ~ 열변수)` | 두 범주형 변수 기준의 격자(grid) 형태 패널 분할 |

- `scales = "free_y"` 등 옵션으로 패널마다 독립적인 축 스케일 적용 가능
- `facet_grid` 예시: 지역(행) × 계절(열) 조합으로 관광객 수 비교
- `facet_wrap` 예시: iris 품종(Species) 3종별로 산점도를 1행 3열로 배치

### 2. 테마(Theme) 및 스타일 디자인

목적(보고서, 발표, 논문)에 따라 그래프 디자인을 변경.

| 함수 | 설명 |
|------|------|
| `theme_gray()` | 기본 테마 (회색 배경) |
| `theme_bw()` | 흑백(black & white) 테마 |
| `theme_minimal()` | 최소 요소 테마 (배경색·격자선 최소화) |

- `theme()` 함수 내부에서 세부 요소 개별 조정 가능:
  - `plot.title` — 전체 그래프 제목 스타일 (크기, 색상, bold 등)
  - `axis.title` — 축 제목 스타일
  - `legend.position` — 범례 위치 (`"bottom"`, `"right"` 등)
  - `panel.grid` — 격자선 표시/숨김
- 주의: 디자인 요소를 과도하게 추가하면 그래프가 산만해지므로 목적에 맞게 절제하여 사용

### 3. 색상 스케일 (Color Scale)

| 함수 | 변수 유형 | 설명 |
|------|-----------|------|
| `scale_color_brewer(palette=...)` | 범주형 | 미리 정의된 팔레트로 명확히 색 구분 |
| `scale_color_gradient(low=..., high=...)` | 연속형 | 저값→고값으로 색상이 점진적(gradient) 변화 |

- 범주형(품종 등): 팔레트 이름 지정으로 각 범주를 명확한 색상으로 구분
- 연속형(꽃받침 너비 등): gradient 방식으로 노란색→빨간색처럼 연속적으로 표현

### 4. 응용 그래프

#### 4-1. 그룹별 산점도
- `aes(color = Species)` 로 품종별 색상 구분 → 이미 기본 강의에서 다룬 내용의 정리

#### 4-2. 다중 패널 그래프 (facet 복습)
- `facet_wrap(~Species)` 으로 품종별 패널 분리

#### 4-3. 회귀선이 추가된 산점도
- `geom_smooth(method = "lm")` — 선형 회귀직선 추가
- `se = FALSE` 옵션으로 신뢰구간(음영) 제거 가능
- `method = "loess"` 로 변경 시 곡선(비선형) 표현 가능
- iris 데이터에서 꽃잎 길이↔꽃받침 길이는 강한 양의 관계 → 직선이 잘 적합됨

#### 4-4. 밀도 함수 그래프 (Density Plot)
- `geom_density(alpha = 0.4)` — 연속형 변수의 확률밀도함수 곡선 표현
- 히스토그램보다 매끄러운 곡선으로 분포 형태 파악
- `aes(fill = Species)` + `alpha` 투명도 조정으로 3종 분포를 겹쳐서 비교
- iris 데이터에서 setosa 종이 다른 두 종과 분포 중심 위치가 확연히 다름

#### 4-5. 색상 매핑 (Gradient 복습)
- 산점도에 제3 연속형 변수를 색상 gradient로 추가 표현

## 핵심 코드/함수

```r
library(ggplot2)
library(dplyr)   # mutate() 사용 시 필요

# 1. facet_wrap — 품종별 패널
ggplot(iris, aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point() +
  facet_wrap(~Species, nrow = 1)

# 2. 구간 변수 생성 (mutate)
iris_ex <- iris %>%
  mutate(petal_width_group = cut(Petal.Width,
         breaks = c(0, 1, 1.8, Inf),
         labels = c("small", "medium", "large")))

# 3. facet_grid — 두 변수 기준 격자
ggplot(iris_ex, aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point() +
  facet_grid(Species ~ petal_width_group)

# 4. 테마 변경
p <- ggplot(iris, aes(x = Sepal.Length, y = Petal.Length, color = Species)) +
  geom_point()

p + theme_gray()     # 기본(회색 배경)
p + theme_bw()       # 흑백
p + theme_minimal()  # 최소화

# 5. 사용자 정의 테마 요소
p + theme_minimal() +
  theme(
    legend.position = "bottom",
    axis.title = element_text(size = 13, color = "navy", face = "bold"),
    panel.grid.minor = element_blank()
  )

# 6. 색상 스케일 — 범주형
p + scale_color_brewer(palette = "Set1")

# 7. 색상 스케일 — 연속형 gradient
ggplot(iris, aes(x = Sepal.Length, y = Petal.Length, color = Sepal.Width)) +
  geom_point() +
  scale_color_gradient(low = "yellow", high = "red") +
  theme_minimal()

# 8. 회귀직선 추가
p + geom_smooth(method = "lm", se = FALSE)

# 9. 밀도 함수 그래프
ggplot(iris, aes(x = Sepal.Length, fill = Species)) +
  geom_density(alpha = 0.4)
```

**주요 함수 정리**

| 함수 | 패키지 | 역할 |
|------|--------|------|
| `facet_wrap()` | ggplot2 | 단일 변수 기준 패널 분할 |
| `facet_grid()` | ggplot2 | 두 변수 기준 격자 패널 |
| `theme_*()` | ggplot2 | 전체 테마(배경·격자선 등) 변경 |
| `theme()` | ggplot2 | 개별 디자인 요소 세부 조정 |
| `scale_color_brewer()` | ggplot2 | 범주형 색상 팔레트 지정 |
| `scale_color_gradient()` | ggplot2 | 연속형 gradient 색상 |
| `geom_smooth(method="lm")` | ggplot2 | 선형 회귀직선 추가 |
| `geom_density()` | ggplot2 | 밀도 함수 곡선 |
| `mutate()` | dplyr | 새 변수 생성/변환 |
| `cut()` | base R | 연속형 변수를 구간으로 분할 |

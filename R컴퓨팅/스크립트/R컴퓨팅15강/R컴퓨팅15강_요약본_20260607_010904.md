## 주요 내용

### 1. VS Code에서 R 활용

- **VS Code**(Visual Studio Code)는 오픈소스 코드 편집기로, 별도 언어 설치 없이 여러 언어를 하나의 에디터에서 통합 사용 가능
- R, Python, Julia, SQL 등 다양한 언어를 Extensions(확장기능)으로 연동
- **R 연동 절차**:
  1. VS Code 설치
  2. Extensions → `R` 검색 후 설치
  3. R 콘솔에서 `languageserver` 패키지 설치 (원활한 연동을 위해)
  4. New File → R Document 또는 `.R` 파일 생성 후 코드 작성 및 실행
- Quarto(`.qmd`) 파일도 VS Code에서 `Quarto` Extension 설치 후 동일하게 활용 가능
- 실행 결과가 오른쪽 패널에 출력되며, 히스토그램 등 그래프도 인라인으로 확인 가능

### 2. Quarto(코어터) 문서 작성

- Quarto는 RStudio, VS Code 모두에서 사용 가능한 차세대 동적 문서 도구
- **파일 형식**: `.qmd` (Quarto Markdown)
- **출력 형식**: HTML, PDF, Word 등 다양하게 렌더링 가능
- **렌더링**: RStudio에서 `Render` 버튼 클릭, VS Code에서 `Ctrl+Shift+K` 또는 Preview 버튼
- **헤더(YAML 블록)**에서 `format: html` / `format: pdf` / `format: docx` 등 지정
- **echo: false** 옵션 사용 시 코드 숨기고 결과만 출력
- PDF 출력 시 LaTeX 엔진 필요 → TinyTeX 또는 RTools 설치 필요
- **RTools** 설치 이슈: R 버전(4.5 기준)과 바이너리-소스 파일 버전 미스매치 시 에러 발생 → CRAN에서 해당 버전 RTools 다운로드 후 재설치 필요
- 교재 예제: 제목/폰트/수식/표/코드 결과가 포함된 Quarto 문서를 `.qmd` 소스 파일로 작성 → 렌더링으로 완성 문서 생성

### 3. Google Colab에서 R 활용

- Google Colab은 구글이 제공하는 클라우드 기반 Jupyter Notebook 서비스
- **장점**:
  - 별도 소프트웨어 설치 불필요 (웹 브라우저만 있으면 됨)
  - 구글 드라이브에 자동 저장 및 버전 관리
  - 실시간 협업 가능
  - 클라우드 컴퓨팅 자원(GPU/CPU) 무료 활용
  - Python, R, SQL 등 40여 개 언어 지원
- **R 사용 절차**:
  1. Google Drive 로그인 후 새로 만들기 → Colab 선택 (없으면 앱 추가에서 설치)
  2. 런타임 유형 변경 → R 선택 (기본값은 Python)
  3. 코드 셀(+Code)에 R 명령어 입력 후 `Ctrl+Enter` 또는 실행 버튼
  4. 텍스트 셀(+Text)에 설명 작성 → 코드 결과와 텍스트를 통합한 동적 문서 완성
- **Python 환경에서 R 활용**: `rpy2` 패키지 설치 후 `%%R` magic command로 Jupyter(Python) 환경에서 R 코드 실행 가능 (참고 사항)

### 4. Shiny 웹 앱

- Shiny: R 기반의 인터랙티브 웹 애플리케이션 패키지
- **설치**: `install.packages("shiny")` — R 버전에 따라 설치 오류 발생 가능, 이 경우 RTools 설치 후 재시도
- **RStudio에서 사용**: File → New File → Shiny Web App → Single File
- **예제 1 (히스토그램 앱)**: 슬라이더로 `Number of bins`를 조절하면 히스토그램 구간 수가 실시간 변경
- **예제 2 (데이터 탐색 앱)**: `mtcars` 데이터를 로드해 변속기(auto/manual), 실린더 수에 따른 연비 분포를 동적 필터링으로 시각화
- **예제 3 (사용자 입력 앱)**: `textInput` + `renderText`로 이름 입력 시 "안녕하세요 [이름]" 출력
- Shiny 앱 개발은 난이도가 높으므로, 이 강의에서는 개념과 실행 방법 이해 수준으로 정리

### 5. 강의 마무리

- R은 데이터과학의 기초 언어이며, Python과 함께 데이터 분야에서 가장 널리 사용됨
- 각 언어를 완벽하게 숙지할 필요는 없으며, 개별 언어의 특징과 기본 구조를 이해하고 필요할 때 참조하여 활용하는 능력이 중요
- 15강 전체 실습 내용은 현업/실무에서 보조 도구로 참조할 수 있도록 기억해 두기를 권장

## 핵심 코드/함수

| 도구 | 코드/명령 | 설명 |
|------|-----------|------|
| R 콘솔 | `install.packages("languageserver")` | VS Code 연동용 패키지 설치 |
| R 콘솔 | `install.packages("shiny")` | Shiny 패키지 설치 |
| R 콘솔 | `install.packages("tinytex")` | PDF 렌더링용 TinyTeX 설치 |

| VS Code | `Ctrl+Shift+K` | Quarto 문서 미리보기(Preview) |
| Colab | `Ctrl+Enter` | 셀 실행 단축키 |

## 과제/시험 관련

- **실습 필수 준비 사항** (강의 중 강조):
  - R 및 RStudio 설치 확인
  - Quarto(코어터) 설치
  - VS Code 설치 및 R Extension, Quarto Extension 설치
  - Shiny 패키지 설치 (RTools 필요 시 함께 설치)
  - Google 계정으로 Google Colab 접속 확인

- **Shiny 설치 주의사항**: 최신 R 버전(4.5)에서 Shiny 설치 시 에러 발생 가능 → RTools 설치 후 재시도 필요, `bslib`/`rmarkdown` 패키지도 함께 설치

- **Quarto PDF 출력 주의사항**: 바이너리-소스 버전 미스매치 에러 시 RTools를 먼저 설치하고 R 재시작 후 시도

- 교재에 Quarto 문서 작성 문법(폰트, 제목 크기, 표, 수식, 그래프 포함 방법)이 상세히 기재되어 있으므로 참고하여 활용할 것

## 주요 논의 사항

### 1. 두 변수 간 관계 시각화

- **산점도(Scatter Plot)**: 두 변수 간 관계를 파악하는 가장 기초적이고 중요한 그래프
- X축과 Y축에 각 변수를 배치하고, 각 관측값을 점으로 표시
- 모형 적합(fitting) 전에 반드시 산점도로 데이터 탐색을 먼저 해야 함
- 확인 가능: 선형/비선형 관계, 양/음의 상관, 이상치 등

### 2. plot() 함수

#### 기본 문법
```r
plot(x, y, main="제목", xlab="X축", ylab="Y축", sub="부제목")
```
- `x`, `y`: 같은 길이의 벡터 (pairwise로 점 찍힘)
- 외부 데이터 사용 시: `plot(x, y, data=데이터명)`

#### type 옵션 (그래프 형태)
| type | 설명 |
|------|------|
| `"p"` | 점(Point) — 기본값 |
| `"l"` | 선(Line) — 점을 선으로 연결 |
| `"b"` | Both — 점과 선 모두 표시 |
| `"c"` | 점 위치 제외하고 선 연결 |
| `"o"` | 점을 통과하는 선 |
| `"h"` | 히스토그램형 — 막대 모양 |
| `"s"` | 계단(Step) — 계단형으로 표현 |
| `"n"` | 공백 — 아무것도 안 그림 (위치만 기억) |

- `type="n"`은 이후 `points()`, `lines()` 등으로 커스텀할 때 유용

### 3. 부가 그래픽 함수

#### points() — 점 추가
```r
points(x, y, pch=1, cex=1)
```
- `pch`: 점 모양 (0~25 숫자로 지정, 각각 다른 심볼)
- `cex`: 점 크기 (상대적 배율)
- `plot(type="n")` 후 사용하면 깔끔하게 커스텀 가능

#### lines() — 선 추가
```r
lines(x, y, lty=1, col="red", lwd=2)
```
- `lty`: 선 종류 (1=실선, 2=점선, 3=파선 등)
- `col`: 색상
- `lwd`: 선 굵기 (Line Width)

#### text() — 텍스트 추가
- 그래프 위 특정 좌표에 문자열 표시

#### abline() — 직선 추가
- 회귀선, 수평선, 수직선 등을 그래프에 추가
- `abline(h=값)`: 수평선, `abline(v=값)`: 수직선
- `abline(lm(y~x))`: 회귀직선

#### curve() — 이론적 함수 곡선
```r
curve(sin(x), from=0, to=2*pi, col="blue", lwd=2)
curve(x^2, add=TRUE)  # 기존 그래프 위에 덧그리기
```
- 수학적 함수를 연속형 곡선으로 그려줌
- `add=TRUE`: 기존 plot 위에 겹쳐 그리기
- 실제 데이터(점) + 이론적 함수(곡선) 비교에 유용

### 4. 그래프 레이아웃

#### par() 함수
```r
par(mfrow=c(행, 열))  # 동일 크기 분할
```
- 그래프 공간을 균등하게 분할
- 실행 순서대로 각 공간에 그래프 배치

#### layout() 함수
```r
layout(matrix(c(1,1,2,3), 2, 2, byrow=TRUE), widths=c(3,1), heights=c(1,2))
```
- `par()`보다 유연한 레이아웃 설계
- 각 영역 크기의 비율(widths, heights)을 자유롭게 지정 가능
- 행렬로 그래프 배치 위치를 직접 설계
- 불균등 분할, 병합 등 다양한 배치 가능

### 5. plot 함수 vs 부가 함수 차이점

| 구분 | plot 옵션 | 별도 함수 (points, lines) |
|------|-----------|---------------------------|
| 커스텀 | 디폴트 값 제한적 | 모양/크기/색상 자유 조절 |
| 사용 시점 | 그래프 생성 시 | 그래프 생성 후 추가 |
| 겹치기 | 불가 | 가능 (덧대기) |

## 핵심 정리

1. **산점도**(`plot`)는 두 변수 관계 탐색의 첫 단계 — 모형 적합 전 필수
2. `type` 옵션으로 그래프 형태를 다양하게 변경 가능
3. `type="n"` + `points()`/`lines()` 조합으로 깔끔한 커스텀
4. `curve(add=TRUE)`로 이론적 함수를 실제 데이터 위에 겹쳐 표현
5. `par(mfrow)`: 균등 분할, `layout()`: 유연한 레이아웃 설계

## 실습 내용

- x, y 벡터 생성 후 plot() 산점도 그리기
- type 옵션 변경 (p, l, b, h) 비교
- points() 함수로 pch, cex 조절
- lines() 함수로 lty, col, lwd 조절
- curve() 함수로 sin(x) 곡선 그리기
- par(mfrow=c(2,2))로 4분할 레이아웃에 여러 그래프 배치
- layout() 함수로 불균등 레이아웃 설계

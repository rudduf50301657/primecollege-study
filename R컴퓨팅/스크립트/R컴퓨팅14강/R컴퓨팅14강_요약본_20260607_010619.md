## 배경

R은 대화형 인터프리터 방식으로 동작하기 때문에, 분석 결과가 휘발성이 높고 코드·결과·설명이 분리되어 재현성(reproducibility)이 떨어진다는 한계가 있다. 이를 해결하기 위해 **동적 문서화(Dynamic Documentation)** 개념이 도입되었다.

- **일반 문서화**: 결과를 별도 텍스트 파일로 저장하는 방식
- **동적 문서화**: 코드, 실행 결과, 설명 텍스트를 하나의 문서에 통합하여, 코드 실행 시 결과가 문서에 자동 반영되는 방식

동적 문서화의 필요성:
1. 분석 절차의 재현성(reproducibility) 확보
2. 중복 작업(이중 작업) 방지
3. 분석 결과를 공유 가능한 형태로 문서화

## 주요 내용

### 1. 분석 보고서 구조 — IMRaD

과학기술 분야 보고서/논문의 표준 구조:

| 항목 | 내용 |
|------|------|
| **I** | Introduction (서론/개요) — 연구 목적, 배경, 연구 질문 |
| **M** | Methods (방법론) — 데이터, 분석 절차 |
| **R** | Results (결과) — 분석 결과 |
| **D** | Discussion (논의/결론) |

논문의 경우 Abstract(초록)가 추가되며, 보고서는 위 구조에 제목·요약을 포함한 형태로 작성한다. 초록은 논문의 핵심을 담아 독자의 관심을 끌어야 하므로 매우 중요한 파트이다.

### 2. R Markdown

- **RStudio에 기본 내장**되어 별도 설치 없이 사용 가능
- Markdown 문법으로 텍스트 작성 + R 코드 청크(Code Chunk) 삽입
- **Rendering** 버튼 클릭 시 코드가 실행되고 결과가 문서에 포함됨
- HTML, PDF, Word 등 다양한 출력 형식 지원
- R 생태계(RStudio) 안에서만 동작하는 것이 제한점

#### R Markdown 문법 요약

| 입력 | 출력 |
|------|------|
| `#`, `##`, `###` | 제목 수준 (H1, H2, H3) |
| `*텍스트*` | 이탤릭 |
| `**텍스트**` | 굵은 글씨 (Bold) |
| ` ~~텍스트~~ ` | 취소선 |
| `-` 또는 숫자 | 목록 (Bullet / 순번) |
| `\| 셀 \| 셀 \|` | 표 (Table) |
| `$수식$` | 인라인 수식 (LaTeX) |
| `$$수식$$` | 블록 수식 |

#### 코드 청크 옵션

- **echo=FALSE**: 코드 숨기고 결과만 출력
- **echo 없음(기본)**: 코드와 결과 함께 출력
- 옵션에 따라 코드 표시/숨기기, 결과 표시/숨기기 조합 가능

### 3. Quarto

- R에 독립적인 **별도 소프트웨어** (별도 설치 필요, [quarto.org](https://quarto.org))
- R Markdown의 개념을 확장·계승하되, **범용 플랫폼** — R뿐 아니라 Python, Julia 등 다양한 언어 환경에서 동작
- 파일 확장자: `.qmd`
- 기능이 더 풍부하고, 복잡한 문서 표현(수식, 참고문헌, 서적 편집 수준)에 유리
- RStudio 내에서 Quarto를 거의 동일한 문법으로 사용 가능

#### LaTeX 연동

- Quarto에서 PDF 출력 시 LaTeX 엔진 필요
- 전체 LaTeX 배포판 대신 **TinyTeX** (R 패키지)로 최소 환경만 설치 권장
  - Windows: MiKTeX 계열
  - Mac: MacTeX 계열
- 수식·수학 공식이 많은 논문·보고서 작성에 적합
- R 컴퓨팅 수업 수준에서는 LaTeX 전체 설치까지는 필요 없음

#### R Markdown vs Quarto 비교

| 항목 | R Markdown | Quarto |
|------|-----------|--------|
| 설치 | RStudio 내장 | 별도 설치 |
| 동작 환경 | R/RStudio 전용 | R, Python, Julia 등 범용 |
| 파일 형식 | `.Rmd` | `.qmd` |
| 기능 범위 | 기본적 문서화 | 확장된 문서화 (서적, 논문 등) |
| LaTeX 연동 | 가능 | 더 긴밀히 연동 |

### 4. Shiny

- R 패키지로 제공되는 **인터랙티브(Interactive) 웹 앱** 제작 도구
- **동적 문서화와 혼동 주의**: Shiny는 정적 보고서가 아니라, 사용자가 파라미터를 변경하면 분석 결과와 그래프가 **실시간으로 업데이트**되는 웹 앱
- ggplot2, plotly 등 시각화 패키지와 잘 연동됨
- RStudio에서 별도 프레임워크 없이 웹 브라우저로 바로 실행

#### Shiny 앱 구조

| 방식 | 설명 |
|------|------|
| **Single-file (app.R)** | UI + 서버 로직을 하나의 파일에 작성. 수업에서 권장 |
| **Multi-file** | `ui.R`(사용자 인터페이스)과 `server.R`(서버 로직)을 분리. 대규모 앱에 적합 |

#### Shiny 기본 사용법

```r
# 패키지 설치
install.packages("shiny")

# 패키지 로드
library(shiny)

# 내장 예제 실행 (인터랙티브 동작 확인)
runExample("01_hello")
```

- `runExample()` 함수로 Shiny 패키지에 내장된 다양한 예제를 바로 실행 가능
- 예제에는 히스토그램, 테이블, 슬라이더 등 다양한 인터랙티브 요소 포함

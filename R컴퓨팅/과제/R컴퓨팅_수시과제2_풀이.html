문제 1
R 반복문을 이용하여 삼각형 형태의 수치자료를 출력 (총 14점)
1) 학번 뒷자리를 M으로 저장하고 출력 (2점)
R 코드
R
M <- c(1, 0, 2, 1, 8, 5) M
실행 결과
[1] 1 0 2 1 8 5
강의 출처: c() 함수로 벡터 생성 → 9강 실습 예제 (벡터 생성 및 할당)
학번 뒷자리 102185의 각 숫자를 개별 원소로 분리하여 벡터 M에 저장합니다.
2) for 반복문 - 각 원소의 제곱값 출력 (2점)
R 코드
R
for (x in M) { print(x^2) }
실행 결과
[1] 1 [1] 0 [1] 4 [1] 1 [1] 64 [1] 25
강의 출처: for 반복문 → 9강 “반복문” 단원 | 거듭제곱 연산자 ^ → 8강 “산술 연산자” 단원
M의 각 원소(1, 0, 2, 1, 8, 5)를 순서대로 제곱하여 출력합니다.
1²=1, 0²=0, 2²=4, 1²=1, 8²=64, 5²=25
3) 사용자 정의 함수 f(x) 작성 (2점)
R 코드
R
f <- function(x) { if (x %% 2 == 1) { return(x * 2) } else { return(x * 3) } } f(3) f(4)
실행 결과
[1] 6 [1] 12
강의 출처: 사용자 정의 함수 function() → 9강 “사용자 정의 함수” 단원 | if/else 조건문 → 9강 “조건문” 단원 | 나머지 연산자 %% → 8강 “산술 연산자” 단원 | 비교 연산자 == → 8강 “비교 연산자” 단원
홀수이면 x × 2, 짝수이면 x × 3을 반환합니다.
if문으로 x %% 2 == 1 (홀수 판별)을 사용합니다.
f(3) → 3은 홀수 → 3×2 = 6  /  f(4) → 4는 짝수 → 4×3 = 12
4) 수열 M에 f(x) 적용 → result 벡터 생성 (2점)
R 코드
R
result <- c() for (x in M) { result <- c(result, f(x)) } result
실행 결과
[1] 2 0 6 2 24 10
M의 각 원소에 함수 f(x)를 적용한 결과를 result 벡터에 저장합니다.
f(1)=1×2=2(홀수)   f(0)=0×3=0(짝수)   f(2)=2×3=6(짝수)   f(1)=1×2=2(홀수)   f(8)=8×3=24(짝수)   f(5)=5×2=10(홀수)
강의 출처: for 반복문 + 사용자 정의 함수 호출 → 9강 “반복문” + “사용자 정의 함수” 단원 | 빈 벡터에 c()로 원소 추가 → 9강 실습 예제
5) while문 - 누적합, 20 초과 시 break (3점)
R 코드
R
sum_val <- 0 i <- 1 while (i <= length(M)) { sum_val <- sum_val + M[i] print(sum_val) if (sum_val > 20) { break } i <- i + 1 }
실행 결과
[1] 1 [1] 1 [1] 3 [1] 4 [1] 12 [1] 17
M의 원소를 순서대로 누적합에 더하며 각 단계마다 출력합니다.
1단계: 0+1=1   2단계: 1+0=1   3단계: 1+2=3   4단계: 3+1=4   5단계: 4+8=12   6단계: 12+5=17
최종 누적합 17로 20을 초과하지 않아 모든 원소를 처리 후 정상 종료됩니다.
강의 출처: while 반복문 → 9강 “while문” 단원 | break 분기문 → 9강 “분기문 — break” 단원 | 누적합 계산 패턴 → 9강 실습 (x <- x+i 누적합 예제)
6) repeat문 - 5 이상이면 next, 모두 처리 시 break (3점)
R 코드
R
sum_val <- 0 i <- 1 repeat { if (i > length(M)) { break } if (M[i] >= 5) { i <- i + 1 next } sum_val <- sum_val + M[i] print(sum_val) i <- i + 1 }
실행 결과
[1] 1 [1] 1 [1] 3 [1] 4
M의 원소를 순서대로 처리하되, 값이 5 이상이면 next로 건너뜁니다.
M[1]=1: <5 → 누적합 1 출력   M[2]=0: <5 → 누적합 1 출력   M[3]=2: <5 → 누적합 3 출력   M[4]=1: <5 → 누적합 4 출력
M[5]=8: ≥5 → next (건너뜀)   M[6]=5: ≥5 → next (건너뜀)
모든 원소 처리 완료 후 break로 종료합니다.
강의 출처: repeat 반복문 → 9강 “repeat문” 단원 | next 분기문 → 9강 “분기문 — next” 단원 | break로 루프 탈출 → 9강 “분기문 — break” 단원

plot102185 <- function(type, data) { if (type == "pie") { pie(data, main = "Cars93 Manufacturer Pie Chart") } else if (type == "bar") { barplot(data, main = "Cars93 Manufacturer Barplot", las = 2) } } # 파이차트 출력 plot102185("pie", tab) # 막대그림 출력 plot102185("bar", tab)

plot102185("bar", tab) → 막대그림 출력
(R에서 실행 후 출력되는 그래프를 캡쳐하여 첨부)

## 주요 논의 사항

### 1. 프로그래밍 언어로서의 R
- R은 데이터 분석 특화 언어이면서 동시에 프로그래밍 언어의 성격을 지님
- 반복문, 조건문 등 다양한 프로그래밍 구조 지원
- Python과 R을 겸비하면 데이터 과학 영역을 넓게 커버 가능

### 2. 산술 연산자 (사칙연산)
| 연산자 | 기능 | 비고 |
|--------|------|------|
| `+` | 덧셈 | Componentwise |
| `-` | 뺄셈 | Componentwise |
| `*` | 곱셈 | Componentwise (행렬도 원소별) |
| `/` | 나눗셈 | Componentwise |
| `^` | 거듭제곱 | Componentwise |
| `%/%` | 정수 나눗셈 (몫) | 소수점 이하 버림 |
| `%*%` | 행렬 곱 | **수학적 행렬 곱셈** (행렬 전용) |

- **핵심**: 모든 일반 연산자는 Componentwise(같은 위치 원소끼리) 연산
- **주의**: `*`(원소별 곱)과 `%*%`(행렬 곱)은 완전히 다른 결과 산출
- 0으로 나눌 경우: `Inf`(무한대) 또는 `NaN`(정의 불가) 출력

### 3. 비교 연산자
| 연산자 | 의미 |
|--------|------|
| `==` | 같다 (주의: `=` 하나는 할당연산자!) |
| `!=` | 같지 않다 (Not Equal) |
| `<`, `<=` | 작다, 작거나 같다 |
| `>`, `>=` | 크다, 크거나 같다 |

- 결과값은 논리값(TRUE/FALSE)으로 반환
- 객체에 값을 할당 후 변수명으로 비교해도 동일 결과

### 4. 논리 연산자
| 연산자 | 용도 | 사용 조건 |
|--------|------|-----------|
| `&&` | AND (스칼라) | 단일 논리값 비교 시 |
| `&` | AND (벡터) | 벡터 논리값 비교 시 |
| `\|\|` | OR (스칼라) | 단일 논리값 비교 시 |
| `\|` | OR (벡터) | 벡터 논리값 비교 시 |

- **AND**: 양쪽 모두 TRUE일 때만 TRUE
- **OR**: 하나만 TRUE여도 TRUE (둘 다 FALSE일 때만 FALSE)
- **주의**: 벡터가 개입되면 반드시 `&`(하나)를 사용 → `&&`(두 개)는 에러/경고 발생

### 5. 집합 연산자 (Vector를 집합으로 간주)
| 함수 | 기능 |
|------|------|
| `union(x, y)` | 합집합 (중복 제거) |
| `intersect(x, y)` | 교집합 |
| `setdiff(x, y)` | 차집합 (x에서 y 속성 제거) |
| `setequal(x, y)` | 두 집합이 같은지 판단 (논리값 반환) |
| `%in%` | 특정 원소가 집합에 포함되는지 확인 |
| `choose(n, k)` | 조합 (nCk) |

- **주의**: `setdiff(x, y)` ≠ `setdiff(y, x)` — 순서에 따라 결과가 다름

### 6. 내장 함수
#### 수치형 함수
- `pi`: 원주율 상수
- `log(x)`: 자연로그, `log10(x)`: 상용로그
- `exp(x)`: 지수함수
- `sqrt(x)`: 제곱근 (square root)
- `sin`, `cos`, `tan`, `asin`, `acos`, `atan`: 삼각함수

#### 최솟값/최댓값 함수
| 함수 | 기능 |
|------|------|
| `min(x)` / `max(x)` | 전체 원소 중 최솟값/최댓값 |
| `range(x)` | 최솟값과 최댓값 반환 |
| `pmin(x1, x2)` / `pmax(x1, x2)` | **Pairwise** 비교 (같은 위치끼리 비교 후 작은/큰 값 반환) |

- `min(x1, x2, ...)`: 여러 벡터를 넣으면 모든 원소를 풀어서 최솟값 산출
- `pmin`/`pmax`: 같은 위치 원소끼리 비교 → 벡터 결과 반환

#### 통계 함수
- `mean(x)`: 평균
- `sd(x)`: 표준편차
- `var(x)`: 분산
- `median(x)`: 중위수
- `quantile(x, p)`: p% 분위수 (`quantile(x, 0.5)` = `median(x)`)
- `cor(x, y)`: 상관계수 (방향성 판단, -1 ~ +1)

## 핵심 정리

1. R의 연산은 기본적으로 **Componentwise** (같은 위치 원소끼리 연산)
2. 행렬 곱(`%*%`)만 유일하게 수학적 행렬 곱셈 수행
3. 비교연산자 `==`(두 개)와 할당연산자 `=`(하나) 구분 필수
4. 논리연산자: 스칼라는 `&&`/`||`, 벡터는 `&`/`|` 사용
5. `setdiff`는 순서에 따라 결과가 달라짐

## 실습 내용

- R 콘솔에서 사칙연산, 행렬 연산(`%*%` vs `*`), 비교연산자, 논리연산자 실습
- 0으로 나누기(`Inf`, `NaN`) 확인
- 벡터 논리연산에서 `&&` 사용 시 에러 발생 확인 → `&` 하나로 해결

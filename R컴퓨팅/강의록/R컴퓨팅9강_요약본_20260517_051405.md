## 주요 논의 사항

### 1. 조건문 (Conditional Statements)

#### if 조건문
- `if(조건) 실행문` — 조건이 TRUE일 때만 실행
- 복수 실행문은 중괄호(`{}`)로 묶어서 사용
- 단일 실행문도 명확성을 위해 중괄호 사용 권장

#### if-else 조건문
- `if(조건) 실행문1 else 실행문2`
- 조건 만족 시 실행문1, 불만족 시 실행문2 수행
- 예: `mean(x) > mean(y)` 조건으로 분기 처리

#### 중첩 조건문
- if 안에 또 다른 if를 넣어 여러 조건을 순차적으로 판단
- 예: 80점 이상 → 합격, 그 중 90점 이상 → 우수, 80점 미만 → 불합격
- 중괄호 짝 맞추기에 주의 필요

#### ifelse() 함수
- `ifelse(조건, 참일 때 값, 거짓일 때 값)` — 한 줄로 컴팩트하게 표현
- **벡터 연산 가능**: 각 원소별로 조건 판단하여 결과 반환
- 중첩 가능: `ifelse(조건1, 값1, ifelse(조건2, 값2, 값3))` → 구간 분류에 유용
- 예: 온도 분류 (hot/mild/cold)

#### switch 문
- `switch(매개변수, 이름1=실행1, 이름2=실행2, ...)`
- 문자열 매칭: 매개변수 값과 일치하는 이름의 실행문 수행
- 정수 매칭: 정수 값이 위치(순서)를 지정 (0, 음수는 무효)

### 2. 반복문 (Loop Statements)

#### for 문
- `for(i in 시작:끝) { 실행문 }` — 가장 직관적이고 많이 사용됨
- 시점과 종점이 명확하게 선언됨
- 예: `for(i in 1:5) print(rep(i, i))` → 1을 1번, 2를 2번, ..., 5를 5번 출력
- 누적합 계산: 초기값 설정 후 i를 증가시키며 x 업데이트

#### while 문
- `while(조건) { 실행문 }` — 조건이 TRUE인 동안 계속 반복
- for문과 달리 **초기값 선언**과 **i 업데이트(i <- i+1)** 를 직접 넣어야 함
- 종점이 명시적이지 않아 조건 설정에 주의 필요

#### repeat 문
- `repeat { 실행문; if(조건) break }` — 무조건 실행, break로 탈출
- 조건이 repeat 자체에 없고, 내부에 break 조건을 반드시 포함해야 함
- break 없으면 **무한 루프** 발생 — 가장 주의 필요

### 3. 분기문 (Branch Statements)

#### break
- 루프를 즉시 탈출 (해당 루프 밖으로 나감)
- for문에서도 사용 가능: 범위 끝까지 가기 전에 조건 충족 시 조기 종료
- 예: 누적합이 25 초과하면 루프 탈출
- 중첩 루프에서는 안쪽(inner) 루프만 탈출

#### next
- 현재 반복의 나머지 실행문을 **건너뛰고** 다음 반복으로 진행
- break와 차이: break는 루프 탈출, next는 건너뛰기(루프 계속)
- 예: `if(i < 8) next` → i가 8 미만일 때는 출력하지 않고 넘어감, 8 이상만 출력

### 4. 사용자 정의 함수

#### 함수 생성 구문
```r
함수이름 <- function(매개변수) {
  함수 몸체(실행 코드)
  return(결과값)  # 또는 마지막 표현식이 자동 반환
}
```

#### 함수의 장점
- **효율성**: 긴 코드를 한 줄 호출로 대체
- **유연성**: 수정/보완 용이
- **가독성**: 스크립트 크기 축소, 코드 이해 용이
- **재사용성**: 한번 정의하면 계속 호출 가능

## 핵심 정리

| 구문 | 특징 | 사용 시점 |
|------|------|-----------|
| `if/else` | 조건 분기 | 단순 참/거짓 분기 |
| `ifelse()` | 벡터화된 조건 | 벡터 각 원소별 판단 |
| `switch` | 다중 매칭 | 여러 케이스 중 선택 |
| `for` | 범위 반복 | 시점/종점 명확할 때 |
| `while` | 조건 반복 | 종료 시점이 조건에 의존 |
| `repeat` | 무한 반복+break | break 조건으로 탈출 |
| `break` | 루프 탈출 | 조기 종료 필요 시 |
| `next` | 건너뛰기 | 특정 조건 무시하고 계속 |

## 실습 내용
